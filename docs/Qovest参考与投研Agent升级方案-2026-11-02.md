## 优先实现的工作流

### 1. 证据补全与核验（先升级现有 Harness）

输入是研究问题、标的身份、期限、用户权限和预算。按问题确定必要字段；区分未授权、无数据、超时、过期、期间不一致。只在缺口有可用合法来源时执行一次有界补取，保留每次尝试及原始来源。基础事实通过确定性程序检查主体、币种、单位、期间、发布时间；复杂语义再交现有审校器。

输出是可用事实、仍缺事实、冲突、来源与时间，以及各类结论允许讨论的范围。财报可用而 PE 缺失时仍可分析已核实的业绩，单独限制估值结论；不能把整份答复降成“全部无法判断”。相反，有评级不代表有盈利一致预期，有市值不代表有 PE。缺失不能补零，也不能从季度 EPS 年化编出 PE。

优先接入快速对话与深度研究共同入口。对话应先显示已核实事实，再逐步显示分析；明确标记尚在补取的字段，避免先发布未经核验结论再静默修改。

### 2. 持续跟踪 Agent（新增任务类型）

每个研究项目固定标的、用户、原始问题、基线结论、关键假设、来源、观察变量、触发阈值和预算。复用现有后台任务与 owner/租约，不开第二套运行时。

触发来自用户设置的周期或已接入的数据更新事件。先比较事实版本，只有相关变量有变化才重做受影响分析；输出“变化、来源、对旧假设的影响、仍待验证事项”。无变化记录检查时间，不反复生成长报告。新消息不是自动交易指令，也不自动成为已验证事实。

需要持久化 project、revision、observation、subscription、delivery 去重键；同一触发重复投递只生成一次修订。与现有 Super-agent 评估中的事件游标、冻结委托、事务 outbox 设计衔接。本文不新建 Codex 定时任务或外部通知。

### 3. 可计算情景分析（扩展现有模块）

首版只做口径明确的 EPS×PE 情景：输入 EPS 年度/币种/来源、PE 假设依据、参考价时间和用户变更；计算器确定性输出价格与相对参考价的变化，LLM 解释假设和限制。没有合格输入就返回缺口，不调用模型捏造数值。DCF、银行PB等方法后续分别定义适用条件，不套同一公式。

假设修改生成新版本，保留原始值与用户值。默认不需要每次拖动输入都调用模型；数值立即重算，解释可按需更新。技术趋势、新闻热度和评级比例不得机械换算为 EPS、PE 或情景概率。

## 产品承载：研究空间

先做单人私有研究项目，复用登录身份和已有材料索引。一个项目展示当前结论、事实来源、假设与反证、待验证清单、历史变更、关联笔记。继续提问时装载有来源的结构化项目状态和最近差异，而不是无界拼接全部聊天历史。用户笔记标为个人观点，不能冒充外部证据。

优先级：证据补全与核验 → 单人研究项目/版本 → 持续跟踪 → 可编辑情景。新增 Agent 数量服从职责和实际收益，现有事实/逻辑/风险角色继续复用。

## 验收与边界

- 固定 A/H/US 以及仅行情、财报缺失、估值缺失、同名异股、累计/单季混淆、过期快照、冲突来源、附件注入等回归用例；增加保留未见测试集，禁止看答案后降低门槛。
- 验证最终回答而非只验证工具：关键数字逐项绑定实际证据；没有证据的估值/预测不出现；部分数据可用时保留有根据的分析。
- 跟踪任务测试重启恢复、重复事件、取消、跨用户拒绝、无变化、来源修订与结果交付失败；旧版本不得被重写。
- 同一负载下测首段可见正文、完整答案的 p50/p95、工具耗时、模型调用数与成本；先记录基线，再预登记预算和通过门槛。不能用假进度、额外串行辩论或无限重试改善表面体验。
- 因果归因要有可说明的方法和数据；没有时只报告相关变化，不仿照宣传案例编出“汇率贡献百分比”。
- 维持内部研究范围；来源可访问不代表拥有商业再分发权。未扩大工具权限、未接券商账户、未改量化策略验证门槛。
