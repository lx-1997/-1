# AI 模拟盘金融执行重放 · 2026-10-30

范围为商业级内部研究，未向外出售数据或信号，未连接券商。策略通过标准、费用率、止损、限仓、T+1、永久回撤暂停均不放宽。本阶段补足可追溯执行与账务检查，不宣称策略获得稳定 Alpha。本轮未部署。

## 查明和修复

1. 旧成交保存的价格取三位小数，但金额由未取整价格计算，导致保存的价格×数量不等于金额。新成交采用 A 股股票 0.01 元价格步长，买入向上、卖出向下取整，金额用该成交价计算。费用率和冲击模型不降低；未来模拟数值会受保守取整影响，版本改为 paper-v2.3，旧记录不重算。
2. 新仓另外保存含买入费的十进制成本金额，平仓按该金额核算已实现损益；保留既有八列持仓表，侧表与现金/成交同事务更新。旧仓没有可信成本金额时维持未知，仅沿用旧均价计算且标明未核验，不倒填准确成本、不清零旧现金的小数余数。这不是全系统已经改成 Decimal 账簿。
3. 采集行情前通过时段检查不代表获取锁时仍可交易。现在在成交事务中再检查，统一使用冻结成交时钟判断报价、成本参考、T+1、休息期和估值。跨午休/收盘后不成交。
4. 候选同分排序、历史同时间成交次序原来依赖容器/SQL 隐含次序。显式保存候选池原顺序和历史 rowid；持仓排序明确。采集期间新加入池外持仓时仍记录实际受阻原因，不因缺少候选键报错。

## 完整金融路径的重放边界

新 journal 为 paper-tick-audit-v2，保存入场/成交时钟、真实配置、候选顺序、当时分析输入、交易前状态和 marks、风险档案、当日净值，以及影响决策的历史成交。历史以 256 行稳定分块存入原不可变内容寻址表，重复前缀复用，不截断历史。原存储额度仍生效，超额拒绝提交，长期容量尚未验收。

`ai_fund_replay` 在独立进程、新临时 SQLite 中恢复这些事实，禁网络、去掉生产凭据，仅调用当前版本的原 `_run_tick`。源码、Python 和 SQLite 版本必须与原记录相同；旧版本拒绝冒用新源码验证，不执行归档源码。学习/换仓实验开关打开时明确拒绝本验证器。附属记忆写入、人设解说、外发事件投递不属于本次重放；比较的是提交当时的 outbox 内容，不是外部系统投递成功。

逐项比较排序、真实阻断原因、报价接纳、风控、休息期、订单、现金/持仓/成本金额/marks、净值和 outbox。另有不调用原成交辅助函数的账务恒等式检查：成交价×数量、分精度、原假设费率、现金流、持仓数量、成本金额、已知成本的已实现损益及现金+市值=净值。REAL 存储比较容差为 1e-8 元，分精度恒等式使用 Decimal 精确比较。`accepted` 要求路径和这些账务检查同时通过；未知旧成本另行报告，不能解释成历史成本全部核验。

操作入口：

```sh
python3 scripts/ai-fund-audit.py verify-execution \
  --db /absolute/path/paper.sqlite3 --fund main --id <tick-id>
```

源数据库以 mode=ro/query_only 读取；验证不匹配或独立账务失败退出非零。重放可复现并不证明供应商原始数据真实、盘口可成交、策略有效或 OOS 通过。

## 实际证据

- 新增 23 项回归，包括真实金融代码的买入、六配置止损卖出、T+1 跨交易日平仓、跌停受阻、跨午休、同分排序、257 条历史分块/前缀去重、并发池外持仓、缺报价/缺估值、账务篡改和独立 CLI 冷备份恢复。数据均为明确合成的隔离测试，没有注入生产。
- 全研究/模拟盘最终回归见 `artifacts/quant-financial-replay-20261030/isolated-regression.log`。既有 async fixture 弃用警告另留日志，不当作本轮新功能证明。
- 对指定生产只读快照，在全新 `readonly-observation` 目录强制 trade=False、禁网络，六账户 168 次打分一致，六个金融执行帧一致，零成交/零 outbox。缺失消息/资金流/财报等仍声明 unavailable，没有重建原生产 tick。
- 关闭源/备份连接，仅将独立归档设为 DELETE 日志模式，再由六次新 CLI 进程首次只读打开冷备份；六个执行帧和独立账务全部通过。`cold-backup-verification.json` 留存结果。这是观察帧的真实快照重放，不能替代合成活跃成交测试，也不覆盖生产恢复演练。
- `original-experiments-reproduced.json` 再次用原封存输入诊断：原两条结果指纹完全一致，OOS 仍分别 -6.573664% / -4.892656%，均失败，没有新候选晋级。
