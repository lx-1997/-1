# 终端阅读界面与交互修复验收 · 2026-10-28

用户提供的截图显示：深度文章上方事件与模拟盘卡占据近半屏，阅读区被雷达、行情条和悬浮助手挤压；要求深度检查、修复 UI/UX 与功能问题并上线。

## 已修复

- 文章、纪要、研报直接展示各自内容；市场事件与模拟盘只挂载于市场页，默认紧凑摘要、按需展开。
- 文章标题、摘要、时间与操作区分层，统一中文阅读字体、搜索框和行距；阅读页面移除重复市场条与雷达。
- 修正全局 zoom 与裸视口 min-height 的冲突，保留工作区原有父子结构；避免整层新 wrapper 破坏个股专注阅读。
- 切换栏目清除上一个栏目的最大化/收起状态；scroll-margin 让标题与搜索不会被固定顶栏遮住。
- 阅读页隐藏关闭状态的重复 AI 浮标，保留顶栏/移动导航入口；账号新手提示不覆盖资料页面。
- 事件摘要请求增加过期响应抑制、失败提示和重试；按认证 revision 重建组件，清除个人推荐旧状态。
- 本地存储禁用时模拟盘仍可展开；明确使用虚拟资金与模拟表现的文案。
- 修正盘前接口既有测试夹具缺失 provider/model/disclaimer 导致的 TypeScript 检查失败，未改变服务行为。
