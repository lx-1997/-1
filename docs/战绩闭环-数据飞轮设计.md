# 战绩闭环 · 参与式数据飞轮引擎设计

> 观点 → 自动兑现打分 → 命中率加权 → 声誉/信号。个人战绩(换不走)+ 群体阿尔法(数据网络效应)的共同发动机。
> 定位:这是**留存引擎**也是**护城河**——每个用户每次表态都在给轮子加速,且自己先受益。零大模型、确定性、合规安全区。
> 复用:`engagement.py`(看多/看空 UI)、`fetch_market_quotes`、K线前复权、`ai_fund._is_trading_day`/`CN_MARKET_HOLIDAYS`、
> `data_store`、**微信定时推送(`weixin_schedule` + `push_to_user`,已上线)**、SEO 公开页、`compliance` 中性化。

## 0. 核心对象:一次「表态(call)」

一次 call = 用户在某时刻对某标的下的**方向判断**,系统快照入场价、到期后用真实行情**自动兑现**。
不是券商下单,是"记录并验证一个判断",故零合规风险(事实展示,非荐股)。

## 1. 数据模型(SQLite,沿用 weixin_bind/ai_fund 风格)

```sql
-- 一次表态
CREATE TABLE stock_call (
  id            INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id       TEXT NOT NULL,              -- deepfocus_user_id
  symbol        TEXT NOT NULL,              -- 归一码 600519 / 00700.HK / AAPL
  market        TEXT NOT NULL,              -- CN/HK/US（决定基准与复权口径）
  direction     TEXT NOT NULL,              -- 'bull' 看多 / 'bear' 看空
  conviction    INTEGER NOT NULL DEFAULT 2, -- 1 轻 / 2 标 / 3 重（权重与限量，见 §5）
  horizon_days  INTEGER NOT NULL DEFAULT 5, -- 兑现视野（交易日，可选 3/5/20）
  target_price  REAL,                       -- 可选目标价（仅展示，不参与打分 MVP）
  source_ref    TEXT,                       -- 触发来源：news:<id> / panel / search（做归因）
  created_at    TEXT NOT NULL,              -- UTC ISO
  entry_date    TEXT NOT NULL,              -- 入场交易日 YYYY-MM-DD（北京）
  entry_price   REAL NOT NULL,              -- 入场时快照价（展示用；打分用前复权序列，见 §3）
  entry_ccy     TEXT NOT NULL DEFAULT 'CNY',

  status        TEXT NOT NULL DEFAULT 'open',  -- open / settled / void / canceled
  settle_date   TEXT,                          -- 兑现交易日
  exit_price    REAL,                          -- 前复权兑现价
  ret_pct       REAL,                          -- 方向化超额收益 alpha（%，见 §3）
  outcome       TEXT,                          -- hit / miss / flat
  call_score    REAL,                          -- 本条得分（见 §3）
  settled_at    TEXT
);
CREATE INDEX idx_call_open      ON stock_call(status, entry_date);   -- 扫描器取 open
CREATE INDEX idx_call_user      ON stock_call(user_id, status);      -- 我的战绩
CREATE INDEX idx_call_symbol    ON stock_call(symbol, status, direction);  -- 群体信号
CREATE UNIQUE INDEX uq_call_open ON stock_call(user_id, symbol, direction) WHERE status='open';  -- 同标的同方向仅一条 open（防刷）

-- 用户声誉聚合（结算后增量重算，或每日全量）
CREATE TABLE user_reputation (
  user_id       TEXT PRIMARY KEY,
  calls_settled INTEGER NOT NULL DEFAULT 0,   -- 已兑现（含 flat）
  calls_hit     INTEGER NOT NULL DEFAULT 0,
  calls_miss    INTEGER NOT NULL DEFAULT 0,
  acc_shrunk    REAL,                          -- 贝叶斯收缩命中率（§4）
  avg_alpha     REAL,                          -- 衰减加权平均超额收益（钱指标）
  reputation    REAL,                          -- 综合声誉分（排序用）
  weight        REAL NOT NULL DEFAULT 0,       -- 群体信号权重 ∈[0,1]
  streak        INTEGER NOT NULL DEFAULT 0,    -- 当前连胜
  updated_at    TEXT NOT NULL
);

-- 分板块战绩（可选，P1.5）：算"你在新能源命中率68%"
CREATE TABLE user_reputation_sector (
  user_id TEXT NOT NULL, sector TEXT NOT NULL,
  hit INTEGER DEFAULT 0, miss INTEGER DEFAULT 0, avg_alpha REAL,
  PRIMARY KEY (user_id, sector)
);
```

## 3. 兑现打分算法(★ 踩坑集中区,务必逐条实现)

**触发**:结算扫描器发现 `open` 且 `交易日(entry_date→today) ≥ horizon_days`。

**取价——必须前复权 + 同一口径**(否则一次除权/送转会被算成 −50% 的"看错"):
1. 拉标的**前复权日线** `qfq[entry_date..settle_date]`,取 `adj_close[entry_date]`、`adj_close[settle_date]`(两端同在当前前复权基准上,除权除息自动抹平)。
2. `move% = (adj_exit − adj_entry) / adj_entry × 100`

**基准相对(alpha)——牛市普涨不算本事,只认超额**(杜绝"闭眼看多"刷分):
3. 基准:CN=沪深300、HK=恒指、US=标普500,同窗口 `bench_move%`。
4. 方向化超额:`alpha = (move% − bench_move%) × (direction=='bull' ? +1 : −1)`

**判定(dead-zone,骑墙不奖励)**:`DZ = 1.0%`
- `alpha ≥ DZ` → **hit**;`alpha ≤ −DZ` → **miss**;否则 → **flat**(不计入命中率分母)

**本条得分(封顶防一击暴富主导)**:`CAP = 15%`
- `call_score = clamp(alpha, −CAP, +CAP) × conviction_mult`,`conviction_mult = {1:0.6, 2:1.0, 3:1.4}`
- 落库:`ret_pct=alpha, outcome, call_score`

**边界(不处理必被钻)**:
- **停牌**:兑现日无成交价 → 顺延至 `horizon + 宽限(10 交易日)`;仍无 → `void`(不计)。
- **退市 / 数据缺失** → `void`。
- **交易日口径**:视野按交易日算,跳周末/法定休市(`_is_trading_day` / `CN_MARKET_HOLIDAYS`)。
- **晚表态**:若表态发生在标的当日已朝该方向异动 >7% 之后,入场基准改用**当日收盘**(不让它白吃已发生的日内暴动)。

## 4. 声誉计算(小样本要诚实,吃老本要失效)

对该用户全部 `settled`(非 void)的 call,按结算日**时间衰减** `w = 0.5^(age_days/90)`(半衰期 90 天):

- **贝叶斯收缩命中率**(防 3 次侥幸命中登顶):
  `acc_shrunk = (Σ w·[hit] + a) / (Σ w·[hit or miss] + a + b)`,先验 `a=b=5`(拉向 50%)
- **衰减加权超额**(钱指标,比命中率更诚实):`avg_alpha = Σ(w·call_score) / Σ w`
- **有效样本**:`N = Σ w`;**置信因子** `conf = N / (N + 10)`
- **综合声誉**:`reputation = avg_alpha × conf`(一致的、衰减后的超额,按样本折价)
- **信号权重**:`weight = clamp(reputation 归一, 0, 1)`,`N<10 → weight≈0`(不进榜、不进信号)
- **连胜** `streak`:最近连续 hit 数(展示/激励用)
- 展示铁律:**永远带样本量**——"命中率 68%(基于 42 次已兑现)",且赢/亏/均值全量如实(像交割单体检)。

## 5. 防刷分规则(参与式飞轮的生死线)

| # | 攻击 | 防线 |
|---|------|------|
| 1 | 闭眼看多蹭牛市 | **基准相对 alpha**,只认超额 |
| 2 | 3 次侥幸命中登顶 | **贝叶斯收缩 + N<10 权重≈0 不进榜** |
| 3 | 吃两年前老本 | **时间衰减(半衰期90天)** |
| 4 | 骑墙不担责 | **dead-zone ±1% 算 flat 不得分** |
| 5 | 全部标"重仓"拉权重 | **重仓档每周限 K 个 slot**,不能全高信念 |
| 6 | 海量撒网留赢家 | **每日上限 + 同(标的,方向)仅一条 open + 得分用均值非计数** |
| 7 | 只晒赢的 | **全量如实展示(含亏损与均值)** |
| 8 | 除权/停牌钻空 | **前复权 + 停牌顺延 + 退市 void** |
| 9 | 亏了就撤 | **撤销仅限创建后 60min 且未异动** |

## 7. 聚合信号(个人闭环长出的群体资产 · 数据网络效应)

按标的、近窗口:`signal = Σ(weight_u × dir_u × conviction_u) / Σ weight_u`
- **聪明钱情绪**(weight 加权) vs **大众情绪**(等权)并列;**背离**(大众多、聪明钱空)= 逆向提示。
- 权重质量 ⇒ 信号增速 > 用户数增速(super-linear)。挂在个股面板 / 快讯 / 首屏。
- 冷启动:用 AI 模拟盘 5 流派 + 复盘产品战绩当"种子预测者"垫底,样本够前信号只做个人工具不外显。
