## 二、总体结论

> **一句话：工程底子扎实，是一个"按机构级标准设计、当前跑在演示态"的平台。** 参数校验（422）、外网失败降级、CRUD 状态流转、MCP 人审治理、RAG 防幻觉普遍到位；扣分集中在 **2 个必现硬 500** 和 **几个数据自洽/降级失效问题**。

### 各工作区评分

| 工作区 | 评分 | 一句话 |
|---|:---:|---|
| 投研（home/圆桌/深度任务/研报库） | ⭐⭐⭐⭐ 4/5 | 圆桌辩论、深度任务、个股体检全链路漂亮；mock 下 `stock-analysis` 必崩 |
| 观察（行情/盘前/日历/央视/信号流） | ⭐⭐⭐½ 3.5/5 | 行情全靠外网（本环境拿不到），盘前/信号流本地可用；央视 502、日历空态 |
| 个股（体检/财报/股东/事项） | ⭐⭐⭐⭐ 4/5 | 扫描优雅降级、诊断/解读多 agent 输出、UI 一键检测端到端跑通 |
| 证据（数据源/研报 RAG） | ⭐⭐⭐⭐ 4/5 | CRUD/分页/RAG/Evals 稳健，"我不知道"防幻觉是亮点；雪球降级正则失效 |
| 策略（组合/回测/期权/供应链/海关） | ⭐⭐⭐ 3/5 | 决策/回测/期权降级是范本；**海关两个 GET 必现 500** 明显拉低 |
| 风险（仪表盘/持仓/宏观） | ⭐⭐⭐⭐ 4/5 | 本地希腊值/风险计算/降级扎实；平仓非幂等导致盈亏重复记账 |
| 系统（设置/工具/技能） | ⭐⭐⭐⭐ 4/5 | MCP 调用强制人审（409）、模型配置热生效，治理设计好 |

### 平台级亮点
1. **降级不是事后补的，是设计进去的**：策略中心明确写"不把 yfinance/OpenBB/Polygon/OpenAI 作为硬依赖"；几乎所有数据接口外网失败时返回**结构化 warnings + 空结果**而非崩溃；前端把 warning 渲染成黄色提示条而非白屏。
2. **校验层一致且精确**：非法枚举/越界/缺必填基本都 422 且逐字段定位；不存在的 id 一致 404；分页越界自动 clamp。
3. **AI 治理到位**：MCP 工具调用未审批 → 409 强制人审；RAG 无命中 → "我不知道，不能编造结论"；圆桌输出带合规免责声明。
4. **前端统一度高**：17+ 中心被 CenterShell 统一成"主标题 + 子标签"范式，新首页 ChatGPT 式收敛，导航清爽。

### 系统性问题（跨模块）
- **A. 个别外网失败未被 try/except 包住 → 硬 500**（海关 snapshot / hs-detail）。同模块其他接口写对了，是一致性问题。
- **B. 写操作幂等性缺失**：平仓可重复执行并重复记账。
- **C. 降级链路"看着有、实际不触发"**：雪球→公众号 fallback 的判别正则匹配不到真实告警文案。
- **D. 控制台噪音**：首页高频轮询行情，每次把 11 条 warning 打到 console（开发态刷屏）。

## 五、修复优先级建议

1. **先修 2 个必现 500（#1、#2）** —— 投入小、收益大：海关两个 GET 套 try/except 降级；`_mock_stock_analysis` 补一个 return。两处都能让"能力完成"从 7/8 回到 8/8、海关页从白屏变可用。
2. **再修 3 个数据可信度问题（#3 平仓幂等、#4 雪球降级、#5 metrics 入参）** —— 这些"看着工作、实则记错账/不降级/静默吞参"的问题比崩溃更危险，因为不报错。
3. **零散打磨（#6–#10）** —— 降级语义统一、schema 补字段、值域校验、入库过滤。
4. **生产化前置（系统自评已列）** —— 接真实认证/RBAC、配置主行情 key、迁出 SQLite、登记 MCP allow-list。
5. **前端噪音（#11、#12）** —— 提交 HomePage 改动消除 dev 报错；行情轮询日志降频。

> 说明：本环境"外网全 403"放大了所有数据为空的现象，但这**不计入缺陷**——只有"本该降级却崩溃/记错账/不触发降级"才计入。在用户的真实本地网络（residential IP）下，多数行情/公告类接口预期可恢复。
