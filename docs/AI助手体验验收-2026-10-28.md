## 真实模型验收发现与补充修复

第一轮真实会员提问“请用三句话解释经营现金流和净利润为什么不同，再列一个需要核对的风险。不需要实时行情。”正常完成并保存，但模型擅自调用个股数据、用茅台回答通用概念，还加入无关的市场归因声明。这是回答质量问题，不能以 HTTP 成功当作体验验收成功。

现有保守概念路由把“核对”和“实时”判为证据需求。精确补丁仅移除末尾明确不需要实时行情及通用风险示例的限定语，再执行原有术语、数字、未知公司/代码、动作及附件检查；增加“为什么”解释语法。具体公司、个人持仓、最新数据、附件等仍须取证。未增加默认公司、未修改额度与权限。

本地 117 项相关后端测试通过；在生产 Python 上先重建候选并跑 106 个路由正反例，随后通过同一部署锁执行 1 文件 2 精确块补丁。基线模块 SHA256 8079c665553ea38f150df0804d9a5e2e107adf6005f85bc8dcaca80b221dcc4c；使用 api-restart --expected-release-id 闸门蓝绿切换。
