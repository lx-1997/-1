# daocaijing Web3 产品与基础设施路线

第一阶段先用 USDC/Base 测试网和模拟资产跑通可验证、可暂停、可退款的闭环，再切主网。

## 三条收入线

- **DeFi**：研究、行情、回测和 Agent 工具按调用收费；机构客户使用闭环钱包和 PaymentIntent，按调用费、托管余额和结算量收费。策略资金由客户自托管。
- **GameFi**：AI 策略竞技场先用链下积分、可复现回测和风险调整收益；收入来自赛季通行证、赞助位和高级数据，NFT 和现金奖励后置。
- **RWA**：第一版登记资产、估值来源、审计材料哈希、现金流事件和权限；链上只存凭证哈希与状态，不存身份和合同原文，不先发行可交易资产。

## 共用基础设施

1. 身份与权限：客户 API Key、Agent KYA、RBAC、双人审批和可撤销 Mandate。
2. 资金账本：PostgreSQL 双重记账；SQLite 仅用于开发或只读缓存；充值必须经过确认数和交易回执。
3. 链上层：Base USDC、HTTPS RPC、重组处理、批量 sweep、幂等键和人工暂停开关。
4. 付费层：x402 只有在真实 receipt verifier 上线后才启用；签名结构校验不等于付款证明。
5. 证据层：来源、时间、签名者、哈希、版本和撤销状态形成不可变事件流。
6. 可观测性：健康、就绪度、余额对账、链上延迟、失败率、回退队列和告警。

## 上线门槛

- 生产配置拒绝默认数据库、默认内部密钥、通配 CORS、零地址和未验证的 x402 路径。
- 测试网完成充值、重复回调、重组、RPC 超时、余额不足、退款和人工暂停演练。
- 资金服务与内容服务分进程、分数据库、分密钥；操作台只允许内网或 VPN。
- 每日备份必须有恢复演练；主网前完成法律意见、KYC/KYT、制裁筛查、营销披露和地区限制。

## 当前检查结果（2026-10-07）

- daocaijing API、Nginx 和 DAO API 可用；公网行情与 readiness 路由返回 200。
- DeepFocus readiness 为 `degraded / 84`，证据数据源、主行情源和 SQLite 持久化仍是短板。
- 服务器内存约 1.8 GiB，核心业务依赖多份 SQLite，不适合直接承载真实资金账本。
- DAO 原始 API 已收口到本机监听，外部入口只能经过 HTTPS 反代。
- Agent Ledger 安全补丁已完成本地测试，尚未部署生产，也没有启用真实资金路径。

## 下一步顺序

2. 完成 Base 测试网充值与批量结算 worker，做恢复、重组和暂停演练。
3. 将研究/行情计费接到 receipt verifier，先小额灰度。
4. 上线链下研究竞技场，再评估积分上链；RWA 先做证据登记。
