# 交割单复盘

策略实验室与持仓监控的“交割单复盘”入口提供文件导入、成交校验和股票长仓 FIFO 复盘。现有行情与回测已经有多源接入，本次不新增需要商业数据授权的外部数据源。

## 用户流程

1. 选择自己的交割单，或下载标记为虚构数据的演示模板。
2. 如果有港股通成交或缺失币种，明确选择实际结算币种。
3. 点击“开始复盘”，核对文件名、有效成交数、未计入记录与提示。
4. 分币种查看已实现盈亏、交易费用、卖出胜率、月度盈亏、个股排行、成交明细及逐行问题。

选择文件不会自动上传。文件与报告仅用于本次内存计算，关闭、退出或换号后清除；不写入平台持仓，不提交券商订单，也不调用外部行情或 AI 服务。

## 支持范围与核算口径

- UTF-8/BOM、GB18030 的 CSV/TSV、券商文本 XLS，以及单工作表 XLSX；最多 2 MiB、5000 条记录。二进制 XLS 需要先转为 CSV 或 XLSX。
- 识别常见中文/英文成交字段及 `="值"` 文本单元格，保留证券代码前导零，按日期、时间及有效原始序号排序。
- 先买先卖配对；买入费用计入成本，卖出费用从所得扣除。有净结算金额时直接用净额，避免再次扣费。“手续费”与独立印花税等组件合计，明确的费用合计优先。
- 按币种、交易市场、证券代码隔离成本账本；既不跨币种加总，也不自动换汇。港股通的币种栏可能与实际结算口径不一致，需用户确认。
- 期初未知成本、缺失成交、余额矛盾、无法确定顺序的同日买卖及复杂证券变动影响的收益保守排除，并显示提示。
- 只统计可确认成本的已实现交易，不含持仓浮盈亏、现金红利或全部账户收益。各标的剩余数量相加只用于核对，不代表组合仓位或市值。

## 接口

`POST /api/portfolio/statement/analyze` 需要登录，接收 `file_name`、`content_base64` 与可选 `settlement_currency`（CNY/HKD/USD）。指定币种只覆盖港股通和原文件缺失币种的记录，正常已注明币种的记录保留原口径。分析结果带 `Cache-Control: no-store`。

`GET /api/portfolio/statement/template` 需要登录，返回 UTF-8 BOM CSV 演示模板。

解析和计算在独立 `trade_statement.py`；路由在 `trade_statement_api.py`，由现有 `portfolio_api.py` 挂载。前端通过 `riskService.ts` 的认证客户端访问。

## 验证

定向后端用例覆盖金额、费用、部分卖出、未知底仓、排序、市场与币种隔离、文件限制及认证。前端用例覆盖明确提交、异常提示、币种/市场显示、模板下载及关闭、换号、退出和迟到响应。

运行测试前将 `DEEPFOCUS_DATA_DIR`、`DEEPFOCUS_CORE_DB_PATH` 指向独立临时目录，使用 `pytest --noconftest` 执行 `test_trade_statement.py` 与 `test_trade_statement_api.py`，避免读取实际账户数据库。
