# 稻草财经优化与上线验收

范围：2026-10-10 整体审计中的缺陷、身份和数据边界、任务和成本账本、存储及交付契约。实现位于隔离工作树 `codex/platform-audit-fixes`。原工作树的其它会话改动保留；并发发布的市场雷达和 AI 速览合并后继续保留。

## 实现与验收映射

| 审计项 | 本次实现 | 验收依据 |
| --- | --- | --- |
| 流式问答变量错误 | 使用独立 run_hint；生产分支保留原有 core adapter 和运行指标 | 普通问答、附件、圆桌、最终结果专项回归 |

| 前端串账号历史 | AuthProvider、会话版本、按账号存储及请求取消；社区等缓存同步隔离 | 账号切换、401、流请求和晚到结果回归 |
| 持仓、回测和 Agent 对象权限 | 全部私人对象读写含 owner 条件；海关任务也绑定发起人 | 双用户列表、详情、修改、删除、取消、重试、事件流测试 |
| 旧 JWT 仍可使用 | 集中验证当前账号、活跃状态、会话和最新角色；异常拒绝 | 改密、会话撤销、删除/禁用账号、数据库异常测试 |
| 并发 AI 额度穿透 | SQLite 事务预占、成功消费、失败释放、租约续期；研究循环和圆桌接入 | 并发上限、澄清免扣、失败/断流/未打开响应、续期故障测试 |

| Docker 缺依赖 | 云端依赖补齐；CI 纳入后端测试 | 清单和部署契约检查；实际服务器运行环境测试 |
| Docker 数据不持久 | 统一 data_path；override > DATA_DIR > 原目录；共享持久卷 | 临时路径、legacy 兼容测试；重建验收脚本进入 CI |
| Android Node 不兼容 | 统一 Node 22，声明 engines，安装嵌套工作台依赖 | workflow 和已锁依赖要求核对；本次不产出 APK |
| 客户端 401 状态错误 | 按会话/API 来源清除登录态，保留 AxiosError | Web/原生来源错误、撤销 token 和取消请求测试 |
| 资讯断线漏拉 | created_at + id 游标、升序分页、过滤空页也推进 | 同时间戳 450 条全部排空；超过一批、权限过滤、非推进游标测试 |
| 空自选恢复 | 仅后端 empty=true 才初始化，明确保存空数组 | 清空、刷新、账号切换和首次账号测试 |
| 写请求回退失效 | 保留网络错误类型；只对明确安全的传输错误回退 | 认证失败、超时、取消、网络错误测试 |
| 立即取消量化任务仍 pending | 取消函数持久化终态；已完成结果入 SQLite；重启恢复中断任务 | 即时取消、运行中取消、重建内存、历史结果、容量与 TTL 测试 |
| 分享/发现路由反代错误 | Caddy 公开后端路由契约补齐 | 静态契约测试、CI HTTP 路由检查脚本 |
| 工作台缺运行时 | 独立 Node 工作台镜像和服务、共享数据目录、upstream 配置 | Docker/Compose 契约测试；生产工作台管理员边界检查 |

架构方面，后端先抽出 portfolio_api、ownership 和 cost_quotas；前端抽出认证、存储、自选同步、历史/游标、时钟及流请求边界。保留模块化单体，未进行无验收依据的大规模服务拆分。Agent 队列领取改为原子条件更新，加入租约与心跳、失去租约后停止执行和过期写保护。量化任务具备持久化结果及明确中断状态。
