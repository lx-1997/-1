# 个股平台证据融合验收说明

本地个股研究台在公开行情、财报、盈利预测、资金分类、真实日线和券商评级之上，新增按当前账号权限读取的平台证据。平台资料进入六维研究、三情景的支持与反证，以及后续经营验证清单。已于 2026-10-13 发布到 https://daocaijing.com。

## 已接入的来源

| 来源 | 读取范围与边界 |
| --- | --- |
| 平台快讯 | 先执行当前账号来源过滤，再匹配公司与可见段落 |
| 平台文章 | 沿用文章会员视图；导语不能冒充全文 |
| 平台本地研报 | 已授权文本；标题、标签、标的清单不能补造正文结论 |
| 投行研报已有解读 | 现有付费权限下的缓存解读，包括传导、影响与验证；标记为已有解读，不取原始 PDF |
| 机构纪要 | 平台当前配置下的公开纪要；短导语、缓存正文分别标记 |
| 名人观点 | 沿用现有白名单与来源配置；未授权时不解析缓存 |
| 专业财报共享库 | 认证可见的共享财报、指标与原文分段，不标作本人上传 |
| 我的已完成研究 | 严格按当前账号 owner 过滤任务、圆桌记忆和已完成计算；历史 AI 分析明确标记 |
| 明确公开的资料库 | 仅纳入已有明确公开来源，排除无 owner 的上传、手动与 Agent 私有内容 |

只读取与当前个股匹配的授权内容。当前检索窗口为最近 365 天，每来源最多扫描 1,200 条、返回 32 条；总可见文本上限 256,000 字符。截断、部分覆盖、无匹配与权限缺口逐项展示。接入来源数量不代表全库已读，也不代表置信度。

## 如何影响研究

平台主线展示“可见文本引用 → 经营传导 → 情景关联 → 接下来验证”。引用绑定原记录、文档 ID、文本版本、段落及字符位置；公司直接资料与行业、同行、上下游背景分开呈现。

当前实现使用段落提取和经营规则提出候选主张。规则提出的传导明确标记为假设；预测观点明确标记为尚未兑现。历史、日期未知、仅摘要或主体关联未核验的内容保留为背景，不作为当前三情景的方向依据。不同报告期与币种尚未核验时，正反观点只作为待复核对照。

文字论据补充情景原因、反证及验证条件，不自动改写数值估值。三情景仍由可追溯的 EPS 与估值倍数计算；固定盈利 ±15%、倍数 ±20% 作为压力假设，不表示预测或概率。

界面先展示判断、正反事实和三情景／真实日线，再展开平台研究主线。默认优先展示公司直接论据，背景线索折叠可达。从情景与六维分析可打开完整论据，再查看来源，返回时恢复滚动与焦点。换账号、会员降级或晚到旧响应会清除上一账号资料。

## 验收边界

后端专项覆盖权限过滤、当前 owner、只读数据库、原记录去重、原句引用、文本版本、资金与价格口径、情景计算不变，以及远程总时限 12 秒且保留本地结果。前端专项覆盖证据跳转、双层返回、焦点、手机布局、引用版本匹配及账号隔离。另完成 TypeScript、Python 编译与前端生产构建。

本任务专项最终为后端 133/133、前端 81/81；正式发布使用生产冻结基线，完整前端 56 套 / 707 项通过，生产 Python 3.11 后端 133 项通过，共 840 项候选测试通过。研报缓存解读的传导、影响与验证字段均已纳入；摘要和导语因预算被截断后仍保持原类别，不会升级为原文或情景方向依据。

真实视觉样本来自此前已授权的贵州茅台资料节选：16 份可见记录、2 条可引用主张。研报标题与标签保留为标题线索；其它未包含来源明确标记为离线样本未覆盖。浅色、深色与 390px 手机预览无水平溢出或浏览器错误。三情景数值在融合前后保持一致。

本次没有使用真实账号完成 9 类来源的在线联调。完整来源的实际命中、账号权限及数据时效仍需在可访问的平台环境中验收；不能由离线节选或合成测试推断全库覆盖。
