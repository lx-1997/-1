# 证券投资咨询资质敞口清单（DeepFocus / daocaijing.com）

> 工程 + 合规常识层面的自查，**非法律意见**。持牌/红线的最终判定请以执业律师与属地监管（证监局 / 网信办 / 通管局）沟通为准。
> 生成日期：2026-06-09。基于对实际代码（prompt / 输出 schema / 公私分层）的逐项审计。

## 0. 一句话结论

- 「收回公开访问」（后端真鉴权，已上线）把**向不特定公众**的最重敞口收掉了——这是对的、也是最有效的一步。
- 但要点破一个关键误区：**登录门槛 ≠ 免资质**。证券投资咨询资质针对的是「向客户提供证券投资分析 / 预测 / 建议」这件事本身，**对公众还是对注册用户都一样**。登录化降低的是「面向不特定公众」这一**加重情节**和网信办对公开荐股的明令禁止，但**平台自己产出方向性结论**这件事，在境内仍然要资质。
- 三类内容必须分开看：① **事实数据**（低危）② **转述第三方持牌研报**（中危，需来源/转载/跨境合规）③ **平台自己生成的方向性结论 / 荐股**（高危，核心资质问题）。
- **审计新发现（之前漏判）**：公众层里 `/api/market-dashboard` 和 `/api/headlines` 并非纯事实——它们含**平台自产的大盘看多/看空 + 仓位操作措辞**与**分析师口吻点评**，是当前**公众层最该先处理**的点。

## 1. 公众层（免登录，优先级最高——"面向不特定公众"是最重情节）

| 端点 | 实际输出 | 定性 | 风险 |
|---|---|---|---|
| `/api/research/wire` 研报列表 | 仅 标题/来源/日期/标的/市场 | 事实 | 🟢 低（但"传播海外投行研报"另有转载+跨境合规，见 §2/§4）|
| `/api/market/quotes`、`/api/realtime/messages` | 行情、快讯（事实） | 事实 | 🟢 低（快讯采编/聚合可能触发互联网新闻信息服务许可，见 §4）|
| `/api/headlines` AI 今日头条 | `why` 字段由模型以**"华尔街顶级投行首席策略分析师"**口吻写"为什么重要 / 影响哪些资产 / 为何关注" | 公开的 **AI 生成方向性点评** | 🟠 中（公开生成式 AI → 触发算法备案；分析师人设+方向暗示偏险）|
| `/api/market-dashboard` 大盘盘 | `overall_signal` = **强烈看多 / 偏多 / 偏空 / 强烈看空**；`overall_summary` 含 **"控制仓位 / 大幅降低风险敞口 / 增加对冲保护 / 建议…"** | 平台自产的**大盘方向判断 + 仓位操作建议** | 🔴 **公众层最高危**（无资质对公众"唱多唱空"并给仓位操作建议，正是网信办《关于规范金融信息服务活动的若干规定》明令禁止）|

**公众层整改（P0，建议最先做）：**
1. **`market-dashboard`**：把 `overall_summary` 的**操作性措辞**（控制仓位 / 降低敞口 / 增加对冲 / 建议…）改为**纯客观描述**（如"多数经典指标处于偏谨慎区间"）；`overall_signal` 的"强烈看多/看空"这类**唱多唱空**表述改中性（"偏积极 / 偏谨慎"），或仅展示客观指标读数。后端源头改最干净（前端展示与否都覆盖）。
2. **`headlines.why`**：去掉"投行首席分析师"人设与"该不该关注 / 影响哪些资产"的方向暗示，改为纯客观"事件摘要 / 涉及主体"；或把 `why` 整体收进登录层。
3. 公众层补一条**常驻免责**：我已加在终端 `bbt-status`（"仅供研究与教育用途，不构成投资建议，据此操作风险自负"），**但前端尚未发布**——随下次前端发布生效。

## 2. 登录层（资质问题仍在，但"面向不特定公众"情节已减轻）

| surface | 输出 | 定性 | 备注 |
|---|---|---|---|
| `vision-analyze` 研报 AI 解读 | `rating`(买入/增持/中性/减持) + `target_price` + `one_liner`(看多/看空) + bullish/bearish | 🟠 **转述第三方券商研报**（prompt 限定"只依据研报内容"） | 须明确**来源标注**："以下为〔机构〕研报观点摘录，非本平台建议"；境内传播境外投行研报另需评估跨境/转载授权 |
| `news/ai-analyze` 快讯 AI 解读 | bullish/bearish"对谁利好/利空" | 🔴 平台自产的方向性解读 | 偏建议；rating/target 通常空 |
| `stock/tear-sheet` / `get_stock_verdict` 个股速判 | `overall_verdict` = **重点跟踪 / 谨慎回避** / 中性观察 + 评分 + "卖方 PM"叙述 | 🔴 **平台自产的个股 买/避 结论**（核心资质问题）| 已确认被中间件收口（不在白名单→匿名 401）、且带免责；非公众终端调用 |
| 多市场决策 action(重点跟踪/回避)、期权 AI(看涨/看跌)、investor agent 资本动作、圆桌 decision、一键检测 verdict、晨报 宏观/组合 verdict | 各类方向性结论 | 🔴/🟠 平台自产方向性结论 | **全部登录层** + **均已带"不构成投资建议"免责（覆盖率 100%）** |
| AgentLoop / HomePage / AIChatPanel 的 买入/卖出 / 推荐评级 | 指令式荐股标签 | 🔴 | 已在工作树改为 **看好/看淡 / 分析评分**（待前端发布）|

**登录层整改：**
- 免责覆盖已 100%（做得好），**但**"不构成投资建议"对**无资质仍提供实质建议**这件事**不是免罚金牌**——监管看**实质重于形式**。
- 真正两条路（二选一或并行）：
  - **路线 A（合规持牌）**：若"个股 买/避 结论、目标价、仓位建议"是核心卖点 → 申请**证券投资咨询业务资格**（或与持牌机构合作/导流）。这是把 🔴Tier1 做实的唯一干净路径。
  - **路线 B（去建议化改造）**：把平台严格定位为"投研工具 / 数据信号"，把所有**结论式 / 指令式**措辞改为**描述式 / 证据式**——`verdict` "重点跟踪/谨慎回避" → 中性"信号偏强/偏弱（仅技术信号）"；个股目标价去掉"建议"框架（保留则标注第三方来源）；删除"该不该买 / 建议仓位"。我做的"买卖→看好看淡、推荐评级→分析评分"是路线 B 的**局部**；要彻底，需把 `tear-sheet` verdict 文案与"卖方 PM"叙述也去结论化。

## 3. 跨切面牌照（不止"证券咨询"一项）

- **经营性 ICP 许可证**：商业化（会员付费）网站通常需要，区别于 ICP **备案**。
- **生成式 AI 算法备案 + 安全评估**（《生成式人工智能服务管理暂行办法》）：面向境内公众的生成式 AI 服务（公开的 `headlines.why`、AI 解读）需备案，金融领域尤敏感。
- **互联网新闻信息服务许可**：自建"快讯"做财经新闻采编/发布/聚合，可能触发。
- **跨境**：境内传播境外投行研报，评估数据跨境与转载授权。
