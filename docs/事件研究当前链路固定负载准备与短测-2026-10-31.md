# 事件研究当前链路固定负载准备与短测

内部商业级质量目标尚未完成。旧价格研究一小时 v2 结论保留，只覆盖原登记负载，不能外推新增的事件、现金证据及年度日历入口。本轮建立单独的固定验收协议与独立只读核验器，没有修改应用内核、原价格负载脚本、原两组实验或策略门槛。

## 固定协议与范围

`scripts/quant-event-service-soak.py` 创建全新隔离目录、独立 JWT 用户和真实 loopback TCP 服务。两组原封存729日日线作为不可变父档案，每组分别覆盖“事后重建”和“当时实际留存”两种信息模式，分布于两个研究账户的四条任务通道；第三个账户持续读取实验、现金证据、年度日历三个空列表。加载31条原现金事实与8份年度通知，每个事件结果含535个研究日且有实际模型持仓/成交；短测的第二组重建路径还发生了正现金支付。它们是已见模型路径，不是新 OOS、真实清算或盈利证明。

每30秒发起四任务，同一账户最多2、全局最多4；每第五条任务请求取消。在四个真实年度日历检查线程等待的屏障处检查额外提交429、相同提交键返回同ID及旁观账户读他人记录404；随后释放屏障，完整执行日历、证据与事件重放。每个完成结果与计时前直接数值引擎计算的同版本基线逐字段摘要相等；取消不得发布部分结果，父档案不得改变，不得产生模拟账户。全部源码、输入指纹、原始观测与进程标识留存，API子进程禁止再创建子进程及非loopback连接，不向数据商发起请求。

正式运行保持3600秒、至少30轮/32完成/10取消/600旁观读取/600心跳；沿用旧协议 read p95≤500ms、p99≤1500ms、create p95≤2000ms、loop p99≤250ms/max≤2000ms、整棵独占进程树≤1GiB、研究库≤512MiB。事件计算发生于API线程内，RSS涵盖所有线程；等待API退出后以控制父进程峰值+已wait API峰值作为整树保守上界，无CPU后代时不能沿用旧五后代公式。该口径区别不放宽总1GiB门槛，任何额外子进程拒绝验收。单本机API worker不是生产SLO、全站容量或灾备认证。

## 已执行结果与保留失败

先前v1短测对两组各一种模式运行通过，但未覆盖完整二乘二矩阵，未被当作最终方案。扩为v2固定交叉协议后，smoke-v3出现监测器ReadError，明确失败。退出代码显示HTTP客户端先关、监测读取后取消的顺序缺口；现改为在客户端上下文仍存活时取消并等待监测器，已失败的监测器异常继续保留，不能忽略异常。19项单元检查包含退出清理及已失败读取不被吞掉。

最终smoke-v4：2轮/8新任务，7完成/7摘要一致，1成功取消，36条旁观读取，4条活跃通道均有模型成交；完整四个父档案不变、未创建模拟账户、槽位/入场任务0。独立复核读延迟p95约18.0ms/p99约77.7ms，创建p95约174.0ms，事件循环p99约24.6ms/max约51.8ms，整树保守上界240,893,952字节，研究库峰值23,535,616字节。已确认自建父/子PID消失、独占端口关闭。独立核验只读SQLite、严格JSON和源码归档，不执行应用或归档代码；原主数据库摘要在核验前后不变。

15项针对真实短测副本视图的破坏检查全部拒绝，包括修改整体/取消计数、丢弃读取或占用观测、改写直接基线、错误RSS/子进程/未等待状态、隐去异常/网络尝试及改动来源归档。测试只覆盖读取视图，未改写原短测库或原始记录。完整工具回归在精确导出源码树上另留收据。
