# 显式财报研究面板与缺失观测保全验收

新增可复现的描述性研究面板组装器及离线CLI，接续单个集团盈利能力特征。每个单元明确提取ID、公司、证券、报告期、知识时钟和两个资产端点；整批明确一种知识模式。所有声明单元按原序保留，缺失单元仍输出原因和缺失掩码，不补零、不静默删除，不生成标签、评分、训练或订单。

定义及边界先于首次面板计算登记，单元结果和基础数据均已见。该面板不是新样本外数据，也不证明截面覆盖、公司可比性、策略盈利或商业级验收完成。

## 关键契约

- 同公司/证券/报告期/绝对知识时刻只能出现一次。UTC与北京时间的等价表示也视为重复，不能换提取版本或资产端点重复加权同一观测。
- 模式属于整批声明，拒绝单元自行携带mode、owner或目标收益字段。真实单元响应须与声明的提取ID、完整请求、版本、源码及缺失状态匹配，不能在组装时偷换时点或资格。
- 每个单元复用所属账户的原特征只读查询，显式引用不可变提取；没有自动发现最新版本。不同单元是分别的只读快照，明确 `global_database_snapshot=false`，不冒称整批数据库事务快照。
- 一个单元出现非所属、缺失提取、非法来源或运行失败时，拒绝整个组装，不将已完成前缀发布为结果。合法的缺报/未可见状态则保留在不完整面板中，不能当作程序成功就宣布数据齐全。
- 非空且最多128单元，声明最多256KiB、最终缩进JSON最多4MiB，合作式工作预算12秒；SQLite忙等待等不能据此称OS硬实时保证。声明开始/结束均有界读取并比较原字节。

CLI先在目标同目录写0600临时文件，flush/fsync后以硬链接原子创建目标名，拒绝已有目标或晚到写者，最后清理临时名。不能用不完整JSON冒充完成结果；没有验证断电后的目录持久性或全站灾备。退出0只表示全部单元算术可用，成功写出且status为incomplete时退出2，核验/组装或I/O拒绝退出1；参数错误和目标已存在也由argparse退出2但不产生新报告，不能只凭退出码认定数据完整。任何状态均不可直接训练或晋级。

## 验证

新增25项案例，加已有单特征、派生和事实存储回归最终105通过、2警告、3.46秒。覆盖缺失/顺序/重复时区/版本、模式和未知字段、预算、所有者及后续单元失败、返回来源或时点错配、源码/合作时限、真实CLI及拒绝覆盖、声明中途变大。原型103项与补充原子发布后的最终105项分别留存，没有把不同源码运行混为一次。

flush失败与晚到目标写者用受控文件系统故障注入：分别不留下目标、保全另一写者原字节，两者均清理临时文件。它们不等于真实断电测试。

既有真实财报冷副本执行最终源码的5个禁网CLI场景：

| 场景 | 结果 |
| --- | --- |
| 历史重建显式4单元 | 4单元全部保留，缺失掩码为false/false/false/true，退出2 |
| 实存模式边界前后2单元 | 保留true/false缺失掩码，退出2 |
| 同时刻换提取版本重复 | 拒绝，无结果文件 |
| 其他所属用户 | 拒绝，无结果文件 |
| 未来知识时钟 | 拒绝，无结果文件 |

前一面板3个既有可用观测、后一面板2个既有观测，其完整单特征JSON与前轮结果相同；不将“检查5个观测”写成所有6个观测均有旧JSON比较。两份面板在原型与最终发布实现之间的完整文件字节也相等；发布加固未改变内容。原库/冷副本main SHA不变，计划文件SHA不变，重复导出拒绝覆盖。没有供应商请求、生产写入、账户操作或训练。
