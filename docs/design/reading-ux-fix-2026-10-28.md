# 阅读体验修复与上线验收（2026-10-28）

用户指出上一版 UI/UX 问题，授权修复、测试后直接上线。本次已发布至 https://daocaijing.com/ 。

## 体验修复

- 分类默认收起为单行，实测 53px。点击展开三级行业及来源/机构/时间/类型，点击“查看结果”收起；保留已选路径与结果数，支持清除。完整分类目录未删减。
- 文章、研报、纪要不再叠加模块介绍标题与说明。机构观点统计默认折叠，内容列表先进入视野。
- 纪要列表简介收为两行、标题字号减小；桌面由面板承担唯一列表滚动，移除内嵌纪要的第二个滚动区域，滚动后可达列表末尾及加载更多。
- 纪要打开全屏独立阅读层，顶部返回栏固定，仅正文滚动。标题只展示一次；保留日期、完整正文、原图、评论与分享。
- 阅读时锁定背景、隔离背景交互，Tab 保持在阅读操作内。返回/Esc 恢复各层滚动位置、分类和按钮焦点。原图放大与分享窗口高于阅读层；隐藏的旧分享弹窗不再拦截 Esc。
- 手机使用全宽阅读排版；深色返回链接提高对比度。
