# 稻草财经网站改版 · 2026-10-28

本轮交付是现有 React 终端网站的本地可运行改版。入口为 src/index.tsx，核心仍是 FinancialTerminal，沿用原有鉴权、接口、账户隔离和研究逻辑。未发布生产。独立静态站页面与原生客户端另行验收。

## 外部规范如何落地

- Appllama：https://github.com/Appllama/appllama-skills/blob/main/skills/appllama-app-design-skill/SKILL.md 。采用信息层级、完整状态、统一图标和视觉节奏。首屏改为两个主要动作和三个实际可操作的研究步骤，移除循环装饰图表及无真实行情支撑的扫描暗示。未连接其素材 MCP，未声称完成竞品素材库研究或原生模拟器验收。
- Emil：https://github.com/emilkowalski/skills/blob/main/skills/emil-design-eng/SKILL.md 。采用高频交互的动效取舍、按压反馈、可中断的 CSS 过渡、焦点可见性和 reduced-motion；统一浮层原点，移除重复悬浮 AI 入口，手机通过底部导航进入 AI。
- Expo：https://github.com/expo/skills/blob/main/plugins/expo/skills/expo-design-system/SKILL.md 。采用 adopt-before-build：沿用现有 ThemeContext 和 CSS 语义变量，不新增第二套主题系统，不迁移 Expo，不引入原生依赖。保留原有涨跌颜色语义。

## 主要变化

| Before | After | Why |
| --- | --- | --- |
| 大面积深色宣传区与装饰扫描图表 | 浅深色一致的文字首屏与可点击研究路径 | 首屏直接通向研究流程 |
| 导航使用多种字符图标 | 同一组轻量 SVG 图标 | 桌面和手机风格一致 |
| 面板颜色、边框与圆角各自定义 | 延用语义变量统一外壳、阅读面板、AI 对话与复盘 | 保留主题选择，降低视觉噪音 |
| 页面整体 zoom 放大 | 响应式间距与文字，zoom=1 | 固定导航及主题操作保持在视口内 |
| 模块切换滚到列表，略过标题 | 切换至模块标题并留出固定工具栏空间 | 保持位置感与明确的页面层级 |
| 多处 AI 入口与营销动效 | 头部/底部导航与克制的状态反馈 | 减少阅读遮挡 |

## 第二轮：完整研究流程验收

根据“做到满分”的要求继续改进，而非将第一轮自评当作完成标准。

- 压缩公开首页的宣传高度，让资讯更早进入首屏；研究中的页面直接显示当前公司，不再重复“我的股票”标题。
- 个股导航提供“带着这只股票问 AI”，预填包含公司代码、事实/假设区分要求的可编辑问题；已有草稿不被覆盖，进入工作区不提交研究请求。
- AI 工作区提供返回原公司研究的入口。保留同一账号会话、同一股票的研究标签；切换账号后清空返回上下文与标签记忆。
- 返回自选时恢复原股票按钮的焦点与可见位置，不保存、重排或改变自选。
- 统一研究台与来源详情的主题变量，去除浅色页面内的深色详情标题；320px 下刷新入口与公司同排，报价/币种/资料日期完整显示。

## 模块分类（参考斧头财信文章页）

初次只观察到文章页的来源与行业筛选。后续进入已授权的登录会话，实际查看文章、研报、纪要和快讯模块：文章按来源与行业筛选，研报按机构与行业筛选，纪要按行业及时间筛选。点击科技行业后未观察到其展开三级目录。来源、机构、时间属于独立维度，不应冒充一级、二级、三级分类。

稻草财经落地为：

| 模块 | 分类维度 |
| --- | --- |
| 我的股票 | 全部、A股、港股、美股；只筛显示，不修改自选 |
| 市场快讯 | 来源、内容主题、既有紧急/利好/利空/一般资讯标记 |
| 深度文章 | 来源、内容主题 |
| 投行研报 | 接口机构、内容主题；保留日期分组，分类命中自动展开 |
| 机构纪要 | 内容主题、调研交流/公司点评/行业观察/其他纪要；保留标题简介与单篇全文 |
| 每日复盘 | 综合、大盘、板块、资金；缺失部分不可选 |
| AI 对话 | 欢迎页按看自选/看市场/看板块/查风险筛选推荐任务，不自动发送 |

来源严格使用接口提供的 source_name/org，不从正文猜机构；主题与纪要类型基于标题/标签匹配，未标明主题仍可通过“其他主题”查看。筛选只作用于已加载内容，界面显示已加载与匹配数量，不暗示全库检索。搜索和原有权限不变。各内容模块独立保存当前筛选；快讯、文章、研报筛选在账号变化时重置；组合筛选在分页之前执行，切换分类回第一页。手机使用横向分类条，纪要简介最多显示三行。

验证：分类、搜索高亮、纪要全文返回、自选/AI上下文与提醒相关4组共22项测试通过；1440/390/320px 实际 React 页面分别操作7个模块，共21个模块/尺寸组合无页面横向溢出。截图为明确标注的隔离样例，位于 artifacts/website-redesign/categories。类型检查与生产构建通过，未上线。

## 三级分类修正与验收

根据用户要求，四个内容模块现已共用真正的三级主题树：15 个一级、36 个二级、109 个三级。完整目录见 [content-taxonomy.md](./content-taxonomy.md)。例如科技与 AI → 半导体 → 存储芯片。切换父级清除失效后代，面包屑支持返回上级；来源、机构、类型和时间可叠加筛选。时间按北京时间自然日计算。

元数据有效路径优先；历史资料按标题/标签辅助归类，一文可属多个主题。所有计数仅对应当前加载内容，不宣称覆盖全库。手机使用三级原生选择器，桌面使用逐级标签。

`/dev/categories` 是仅开发环境开放的隔离验收页面，8 条记录全部明确标记为样例。真实本地 API 不可用时不以样例替换业务数据。浏览器实际验收科技与 AI → 半导体 → 存储芯片后匹配 1 条，320px 宽度没有水平溢出。截图位于 artifacts/website-redesign/hierarchy/desktop.jpg 与 mobile-320.jpg。26 项相关测试及生产构建通过，尚未部署。
