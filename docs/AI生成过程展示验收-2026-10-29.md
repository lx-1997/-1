# AI 生成过程展示

2026-10-29，用户要求生成时暴露过程，避免只有等待动画。

## 实现

- 研报/文章等待页改为实际执行记录和秒表，移除随耗时渐近增长的百分比及自动切换的“提炼事实/核对风险”等推测阶段。
- 研报 SSE 的 `ready` 事件也进入界面，显示真实原文页数、文本量或扫描版信息；原始 `thought` JSON 片段继续忽略，不展示模型内部思考。
- 后台任务最多保留12条最近阶段事件；同阶段重复心跳不增加记录。关闭再打开跟随原任务，初步速览出现后过程仍保留，最终结果完成后替换等待页。
- 距最近一次服务更新超过15秒时，如实显示等待时长，不凭时间推进下一阶段。
- 对话默认展开来源执行列表，显示查询中、已返回或未能取得资料；服务端提供摘要时显示摘要。资料调用都已返回时显示正在等待回答生成，后续新工具事件仍继续更新。
- 对话活动指示改为不定进度，不将阶段数当作完成百分比；调整浅深色主题变量和字号，提高手机浅色模式对比度。
- 文章解读现有 POST 没有服务端分步事件，只显示已发起请求、等待及已用时间，并保留可读来源正文；不推测具体模型子步骤。
