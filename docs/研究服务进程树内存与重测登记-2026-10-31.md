# 研究服务进程树内存口径与 v2 重测登记（2026-10-31）

仅内部研究、商业级质量研发；未上线、未开新账户、未改变两组策略资格或原数学引擎。v1 一小时通过的是其原注册协议，因只测 API 自身 RSS，整组内存未验收；本次不重写 v1 的计划、结果和审计结论。

## 修复统计盲区

Mac 旧 process_scope 会调用一次 sysctl 子进程。短命探针可能躲过周期采样，且计算进程在等待探针时被取消，会使后代退出/资源归属更复杂。现以 ctypes 调用固定键 kern.bootsessionuuid 的原生 sysctlbyname，限制缓冲区 2—128 字节、终止符和规范 UUID；错误或未知身份仍返回 None，绝不放宽回收条件。实际本机结果与原 sysctl 命令逐字一致，身份摘要格式不变，Linux 分支不变。

固定私有 quant_cpu_worker 在导入应用前安装审计钩子，拒绝连接网络、subprocess、fork/posix_spawn/exec/system 等进程创建；计算只读原留存输入并写原进度/结果。API 负载工具也只允许固定 Python -B -m deepfocus_api.quant_cpu_worker 子命令，拒绝其他进程创建。生产普通 API 不安装负载工具的审计钩子，未改变其他模块的网络能力。

原槽位全局 4 / owner 2；真实 Popen.wait 之后才清 child/释放槽位，因此一个 API 至多有四个共存计算子进程，每个计算子进程不再有后代。取消和超时仍先真实排空，不提前释放。

## 上界与操作系统证据

RUSAGE_CHILDREN 的最大 RSS 不是整个树的总量。固定拓扑下，以 API 自身生命期峰值 A 和所有已回收子进程中的最大峰值 C，计算 A + 4C。这是保守上界，允许共享页与不同时刻峰值重复计数，不能叫“实测同时峰值”。最终必须确认所有子进程已 wait、SIGCHLD 未忽略；活子或意外僵尸均拒绝验收。最终 largest child 为 0、错误次数非零、子进程创建计数与提交数不符也拒绝。

为了覆盖 API 最终输出与退出前的峰值，控制父进程在真实 wait API 之后再读取内核资源收据。令 P 为控制进程自身峰值，D 为其已回收后代中的最大生命期峰值，整个受控树（控制父 + API + 至多四个计算进程）的内存上界为 P + 5D；该上界同样必须 <= 1GiB。父收据独立 full_soak_passed，API 返回 0 而整个树超限仍返回 2，不能只看 API 的绿色摘要。

本机独立新解释器的实际校准包括：128MiB 分配后立即退出、64MiB 分配后被 SIGKILL 再 wait，以及 256MiB 孙进程被中间父 wait 后再向顶层汇总。峰值在短命进程消失后仍保留，后续小进程不覆盖旧峰值。Darwin 原始数值为字节，Linux 规则转换 KiB；当前实测环境仅 Darwin，Linux 只有单位分支测试，不冒称完成 Linux 服务容量测试。

Apple 原始代码 calcru/getrusage/ruadd 及退出回收路径支持峰值单位与递归汇总语义；匿名下载的两份文件及 SHA 留 artifacts/quant-tree-memory-20261031/primary-sources.json。另两个 URL 的下载失败也保留，不把旧网页的千字节描述当成本机单位。来源：[Apple kern_resource.c](https://raw.githubusercontent.com/apple-oss-distributions/xnu/main/bsd/kern/kern_resource.c)、[Apple kern_exit.c](https://raw.githubusercontent.com/apple-oss-distributions/xnu/main/bsd/kern/kern_exit.c)、[Linux getrusage 手册](https://man7.org/linux/man-pages/man2/getrusage.2.html)。这是本地工作负载的有前提上界，不是跨平台硬隔离或内核内存限额。

## 固定 v2 验收条件（执行前登记）

v2 保留 v1 的全部时长、请求负载、取消频率、认证隔离、结果精确相等和延迟/磁盘上限，增加完整树内存条件：3600 秒、30 秒一轮、四并发/两 owner、每五次任务取消一次；读取 p95 <=500ms / p99 <=1500ms，创建 p95 <=2000ms，心跳 p99 <=250ms / 最大 <=2000ms；QR 含 WAL <=512MiB；API+子和整个受控树上界均 <=1GiB，并要求实际退出/无遗留子/槽位/账户。最低 32 完成、10 取消、30 轮、600 读取与心跳，0 非预期错误/外部连接/生产写入。不能缩短测量、减少并发或增大上限。

运行命令是 backend/.venv/bin/python scripts/quant-service-soak.py --workspace <全新绝对目录> --experiments artifacts/quant-strategy-20261030/frozen-experiments.json --mode full。开始时计划记录原始输入、20 源摘要、依赖版本、3600 秒协议和 3840 秒父预算；运行期间不修改这些源、不并行重 CPU 回归。full 只有 API 条件与最终父收据均通过才成立，结束后仍需独立复核。策略/PIT/许可/真正未见样本等商业验收项独立，不因工程通过改判。
