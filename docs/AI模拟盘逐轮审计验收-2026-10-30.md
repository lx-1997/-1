# AI 模拟盘逐轮审计验收 · 2026-10-30

本阶段服务“先内部研究、达到商业级质量”的目标。新增证据留存、无成交原因和只读复核，不改选股参数、费用率或风险门槛，不改判旧策略失败结果。当前版本尚未部署。

## 已实现

每次 tick 记录配置、实际读取的行情/历史日线/资讯、逐股分析时间、实际参与打分的用户表态值、市场和情绪状态、全部候选、排序、仓位预算、未成交原因，以及成交前后账户和风险状态。消息只保存适配器实际返回的字段，不把采集时间冒称公告首次发布时间；完整上游时点质量仍需验证。

交易与审计在同一个 SQLite `BEGIN IMMEDIATE` 事务内提交。新增成交用 audit_id 关联该轮证据；容量、格式或审计落库失败会回滚现金、持仓、净值、成交和 outbox，不会继续留下无审计成交。没有行情、无法给持仓估值及只观察不交易的轮次也保存状态。计算失败在原事务回滚后记录失败类型，不保存可能含敏感内容的异常文本；若存储本身不可用，失败记录也无法保证落盘，但没有交易提交。提交后的附属解说失败不能将真实已提交的成交改称失败。

私有证据使用内容寻址压缩存储，同一源码/行情快照可复用；每个账户按序号和前一记录摘要链接。普通 SQL 更新/删除被触发器拒绝，读取校验清单、压缩内容、摘要、源码包及直接前序关系，新提交前还检查已有尾记录。完整链用独立只读复核命令逐条检查。保存当时完整的相关 Python 源码及 Python 版本，当前版本不匹配时拒绝冒充原版复核，绝不自动执行证据内的源码。

这提供意外损坏检测和常规操作的不可变约束，**不是对持有数据库文件写权限者的独立可信时间戳或防篡改证明**。离机备份/外部摘要锚定和周期完整链检查仍需生产运维验收。

单段原始输入上限 4MiB、单轮 12MiB、累计压缩 blob 与清单有效载荷上限 512MiB，达到 80% 可通过操作工具看到预警。容量不包含 SQLite 页、索引和 WAL 空间，不能据此宣称总磁盘占用有同样上限。超过额度拒绝新提交，不静默删历史；归档/扩容/告警的生产运维仍须完成。

没有新增公共原始输入接口。现有快照和榜单只增加审计覆盖计数/最新轮次摘要，成交展示可携带 audit_id。无审计的旧成交继续计入 unlinked_trades，既不回填版本，也不补造输入。

## 复核的范围

`verify-analysis` 使用记录中的原配置、行情、资讯、市场状态、分析时间和当时表态重新计算六种配置的打分结果，不读取今天的反应、行情或消息。返回 `execution_replayed=false`、`oos_validation=false`，只证明分析层可复现；不冒称全执行重放或新的样本外验证。非有限输入保留为明确无效值，不可据此获得复核通过结论。

每股实际未买入的首个拦截原因来自真实执行分支，包括无报价、已有持仓、当轮已卖、回补冷静期、当日开仓限制、历史回撤暂停、买点/分数/熊市确认、情绪/连亏停手、时钟/涨停、陈旧估值、预算不足和仓位限制。它不是对所有未到达分支的反事实解释。

### 冷备份注意

第一次备份后直接跨进程只读打开曾失败；验证流程改为明确关闭备份连接、只对**独立备份文件**设置 `journal_mode=DELETE`，再在其他进程首次只读打开通过。不能依靠 sqlite3.Connection 的 with 语句关闭连接，也不能靠先读写打开备份生成辅助文件来掩盖冷启动问题。主库继续使用原有 WAL，未改其日志模式；测试已覆盖冷备份首次跨进程复核。

## 只读操作入口

```sh
python3 scripts/ai-fund-audit.py list --db /absolute/private/paper.sqlite3 --fund main
python3 scripts/ai-fund-audit.py storage --db /absolute/private/paper.sqlite3 --fund main
python3 scripts/ai-fund-audit.py verify-chain --db /absolute/private/paper.sqlite3 --fund main
python3 scripts/ai-fund-audit.py verify-analysis --db /absolute/private/paper.sqlite3 --fund main --id FROZEN_TICK_ID
python3 scripts/ai-fund-audit.py export --db /absolute/private/paper.sqlite3 --fund main --id FROZEN_TICK_ID --output /absolute/new/private-proof.json
```

导出是内部研究材料，文件创建权限 0600，拒绝覆盖已有文件。观察演练入口 `scripts/ai-fund-audit-observe.py` 必须用全新绝对工作目录，拒绝覆盖旧数据库；它禁止网络且不生成交易，不得部署为生产登录或交易入口。
