# AI 对话账号隔离与界面精简验收（2026-10-19）

个人历史固定按当前认证账号的稳定 ID 查询；管理员打开个人历史也只能读取本人记录。原先共用的 owner_filter 对管理员移除条件，是本次跨账号展示的主要原因。服务端 user/user:* 查询现在使用 owner_user_id 等值条件，缺少身份返回空；HTTP 私有历史仍要求登录，不使用标签匹配代替身份。

前端只接收 owner_user_id 与当前账号 ID 相符的历史；会话 revision 同时保护云端响应、本地历史 setter 和 A→B→A/同账号重新登录。账号切换关闭浮层并清理搜索、重命名和当前正文。新对话递增会话版本，取消深度请求后迟到的成功、错误或 finally 不再覆盖新对话。

旧版本管理员查询可能已将其他人的记录合并到本地，故启用新的对话与任务历史命名空间，从严格过滤的云端重新加载本人记录。旧 localStorage 数据保留原件，不自动迁移、认领或删除；旧的本地自定义标题等未经验证内容不直接导入。停止把无主解读缓存和历史分配给首个登录账号。

浮层缩为新对话、最近 5 条标题与日期、全部对话入口；去掉答案摘要和重复输入框。点历史实际打开对应正文。完整工作区保留历史搜索、改名/删除与问答输入，去掉重复新建入口、研究流程宣传条及模式徽章。修复浅色主题标题和搜索框对比度；保留解读记录页签与后台任务能力。
