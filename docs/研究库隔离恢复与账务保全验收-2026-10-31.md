# 研究库隔离恢复与账务保全验收

内部研究工程子阶段，2026-10-31。新增离线恢复工具，只在**全新隔离目录**生成待复核副本，不激活服务、不写生产库。策略门槛、风险峰值、原始失败实验和成交内核均未改变；商业级整体验收仍未完成。

## 恢复规则

`scripts/quant-recovery.py prepare` 只读打开指定的既存研究库，使用 SQLite backup API 获取包含已提交 WAL 的一致快照。副本先使用临时文件名，完成隔离后才发布为 `research.sqlite3`；关闭写连接并转为 DELETE 日志模式，由新 Python 进程首次独立只读打开并核对。不执行归档应用代码，不迁移源库，不清理源库占额。

| 副本记录 | 允许的唯一变化 |
|---|---|
| queued/running 任务 | 标为 failed，固定隔离说明和更新时间；payload 保持逐字节不变 |
| active 模拟账户 | 状态 paused、revision 加一和更新时间；全部金融 payload 保持逐字节不变 |
| 已 paused 账户、已终止任务 | 整条记录不变 |
| 工作槽位 | 仅新副本清空，禁止继承旧 PID/token 并自动继续计算 |
| 现金、持仓、峰值、永久暂停、成交、曲线、实验结果和原文 | 不变 |

按稳定主键排序，对每张表的每行做类型保留的内容摘要；BLOB 比较长度和 SHA256。恢复前算出允许变更后的预期摘要，独立进程核对实际摘要、完整性、请求/结果/数据指纹、同 owner 原文引用及 PDF/HTML 字节。元数据与验证文件由 READY 摘要链绑定，任何已有目录都拒绝覆盖。损坏数据、未知表、可变表的未知触发器、非有限现金、版本或验证链变化拒绝通过；失败尝试留 FAILED，不生成 READY。

目录权限 0700、数据库 0600。默认数据库预算 1GiB，单条主要载荷支持至 32MiB；磁盘须另留 64MiB。备份回调预算和独立验证超时各最多 60 秒，**不是整个恢复流程的硬性 60 秒 SLO**。实际工程不因此声称支持任意规模的数据库。

## 实际证据

19 项新增测试通过，覆盖有真实模拟成交与未卖持仓的合成回放账户、永久回撤暂停保留、取消后仍占额、WAL 已提交行、字节预算/超时、重复路径、损坏原文/引用/结果、未知结构、数据库和验证链篡改。资金测试不是始终空仓的形式验证，也没有为真实失败策略绕过准入。

另在全新离线库导入两组真实封存实验，先以当前数学内核精确复现原结果；导入已留存的 31 个现金事实及 31 份 PDF、8 份交易所年度计划 HTML。保留源库已提交 WAL，在另一个新目录恢复。源库所有表逻辑摘要前后全等，副本两个完成实验与原文保持不变；一条仅用于测试的未完成任务隔离，两条合成占额清空。没有实际计算线程重启，没有创建模拟账户。原两条结果摘要分别为：

- `9ee4efbf59a5766128a552bdc27c598147bfd3903aa63ec9a497da0d7b8ad18e`
- `aafd4d724bdfb673222374e6a9502fa26b72145ae275f6bd1ab672ce797c4ebd`

薄结果见 `quant-recovery-results-20261031.json`。原始记录、19 项定向日志、真实演练脚本/报告、精确源码树及完整后端/三套客户端运行结果保留在 `artifacts/quant-recovery-20261031/`；完整门禁以该目录 `exact-gate.json` 的实际退出码为准。行情、PDF、HTML 不提交 Git。

## 操作入口与边界

```sh
python3 scripts/quant-recovery.py prepare \
  --source /absolute/existing/research.sqlite3 \
  --workspace /absolute/new/recovery-review
python3 scripts/quant-recovery.py verify \
  --workspace /absolute/new/recovery-review
```

READY 只代表此版本副本已隔离并通过存储核对，`activation_authorized` 始终 false；不是上线许可。源库可以有其他写者，快照不声称一直等于备份完成后的最新源库。摘要链提供一致性核对，不是外部签名或抗拥有全部文件写权限者的真实性证明。

本阶段仅涵盖 QR 研究库，不涵盖登录库、六个新闻模拟账户库或整站灾备；未验收跨主机激活、RPO/RTO、长期负载、生产恢复演练。金融载荷保存不代表原价格、历史证券状态、全公司行为或盈利能力已经正确。没有放宽门槛、解除永久暂停、挑选挑战者或部署生产。
