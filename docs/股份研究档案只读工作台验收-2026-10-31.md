# 股份研究档案只读工作台验收

本轮范围为内部研究、商业级质量，未部署到生产，也不生成策略或实盘订单。它把既有不可变股份资料和数量复核接入研究工作台，方便审阅来源时点、历史重建与待决权益；不是策略增益证明。

## 行为与边界

- 原策略工作台新增“股份档案”入口，同一路径 `workspace?view=shares` 使用独立 CSP 脚本摘要。资料 API 必须有真实有效登录会话，并按 owner 过滤。
- 只提供四个 GET：股份资料列表/详情、复核列表/详情。没有上传、创建复核、下单或晋级入口，不返回原文、供应商地址、持仓批次、源码映射或完整账簿。
- 读取使用只读 SQLite 事务，不初始化空库。分页按时间和 ID 稳定下钻；页面最多十项，读取占额为全局四个、每个用户两个。HTTP 取消后，线程真正退出才释放额度。
- 当前源码匹配时校验原文、来源关系和数量结果；旧版本仅展示元数据，隐藏数量，不执行归档代码。旧版本测试是隔离合成失配，不冒称验证过真实历史账户迁移。
- 公告生效日、实际入库时间、首次系统可用时间分别展示。假设持仓、人工快照均不等于券商清算认证；历史重建不等于当时已知。未知入账显示“—”，待获配保留精确零碎权益，不能逐批取整。
- 桌面左右分栏，手机纵向阅读；摘要和审计标识折叠。账号切换清空旧数据，旧请求不能覆盖新选择或新账号。页面不提供交易许可。

## 实际验收

本机临时服务 `scripts/quant-share-workspace-qa.py` 只绑定 loopback，使用全新数据库、真实 JWT 和已核对发行人 PDF；100 股和 1 股均为明确的假设持仓。测试登录入口不得发布。验收源摘要与记录在 `artifacts/quant-share-workspace-20261031/acceptance.json`，测试数据不提交 Git。

账户 A 实际显示两份资料、三条复核：100 股的事后数量模型新增 80 股；1 股产生精确 0.8 股待决权益，已入账显示“—”；历史实存视点显示“当时资料不可用”，不能断言没有权益。账户 B 页面为空，跨账户资料及复核均 404，匿名 API 401。GET 前后研究数据库及 WAL 字节摘要相同；实验、模拟账户、工作槽表均为零。内存 admission 未由该探针直接观察，不声称其独立验收。

实际桌面截图 `desktop.png`、手机 `mobile-pending.png` 和空账户 `mobile-owner-b.png` 已留存。请求手机视口 390×844，实际 document clientWidth/scrollWidth 均为 375，无横向溢出。隔离服务经拥有的 PID/监听核对后 SIGTERM，执行会话退出 143，PID 消失、端口关闭；不是自然退出 0。没有供应商请求或生产写入的业务代码路径；这不是独立网络出口审计。

定向 API 十项通过，客户端检查包含转义、待决非零入账、旧版本隐藏、选择竞争、账号在 JSON 解析期间切换及 HTML 错误响应。最终提交树的完整回归另存测试收据。

## 仍未完成

只读工作台没有把股份与现金、税基、净值、订单及真实清算账单整合。资料次日可用边界尚未由实际墙钟跨越验证。原两组 OOS 和预登记消融结论不变，没有合格挑战者；已见数据不得再次称样本外。

本轮修改了 `quant_research_api.py`，原一小时 v2 负载仅证明原登记源码/价格负载，不能覆盖本次 API 版本或新读取功能。当前并发边界有隔离测试，尚没有新版本持续负载、生产 SLO 或全站 RPO/RTO 证明。商业级整体验收仍未完成。
