# 模拟策略 v2 工程验收

本轮修复代码审查确认的交易安全、数据与账务问题，仅用于模拟盘；没有接入券商或真实资金。工程回归通过不能证明稳定盈利，不能据此将系统评价为机构级“满分”。

## 已实现

- 新闻：只有标题明确提及目标公司的有效时间事件才能进入消息面评分；剔除未来/缺失时间、重复标题、明显供应商/客户事件和他家公司标题的正文提及。未解决完整自然语言因果推断，产业链关联不能冒充直接利好。
- 退出：保留硬止损和盈利后的移动止盈；逆向模型按企稳失败、回归均值和持仓时间退出，价值模型按质量/估值论点退出。公共 MA20 破位规则仅作用于趋势类模型。
- 报价：禁止零现价退回昨收成交；要求正价格、同一交易日的有效报价时间、时效和涨跌幅字段。无有效执行报价不能买卖；行情过期只可作为标记陈旧的估值。盘后可选择带时间的更近报价，不冒充可交易报价。
- 仓位：新增仓位预算同时受单笔净值风险 0.5%、单股 20%、总仓位 80%、人工定义风险组 35% 约束；账户从历史峰值回撤 8% 后暂停新增风险。既有大仓不会被强制清仓。这些是研究期保守初值，不是经收益优化验证的参数；跳空、跌停和 T+1 可能导致实际损失超出预算。
- 学习：活动决策使用冻结基线；暂停平仓与浮盈浮亏调权重，关闭未经完整执行验证的评分换仓。既有学习记录保留，API 不再将旧权重漂移展示为正在生效。
- 费用：新成交模拟佣金万分之 2.5（最低 5 元）、卖出税费万分之 5、双边过户费十万分之 1，属于明确的模拟假设，不代表任何券商真实收费。买入成本含费用，现金/净已实现盈亏/盈亏比一致；历史成交不追溯补费。
- 数量：科创板最低 200 股、其后按 1 股递增；其它当前池按 100 股整手。费用不足时下调数量，现金不透支。
- 原子性：状态读取与成交写入在 `BEGIN IMMEDIATE` 下串行化；并发 tick 不重复建仓或写回旧现金。成交事件先随主账写入 outbox，主账提交后才投递，确认持久化后标记完成。外围事件至少一次投递并携带唯一成交 ID，不能把它说成跨库恰好一次；主账成交唯一。
- 净值：日末快照与历史峰值/最大回撤独立持久化，不随 1440 条原始观测裁剪而消失；休市日不增加风险指标的交易日样本。榜单和详情共用盘中观测回撤口径，保留原 API 符号惯例。
- 年化指标：至少 60 个日净值点才展示；不使用未来基准值回填更早日期。当日日线缓存与实时价不重复计成两个交易日。
- 版本：新成交标记 `paper-v2.0`，历史记录标记 `legacy-v1`；页面提示“研究验证中”、费用口径和风险预算，保持收益率为主。

## 验证证据

生产 Python 3.11 完整候选 209 个生产 Python 文件：139 项相关测试通过，覆盖策略引擎、因子模型、交易费用、并发、事务失败、outbox、时钟、日线重复、实体事件、回撤留存及共享数据存储。另在试验换仓路径显式打开时复验 T+1 和涨停限制，两项通过，避免因默认关闭而产生空洞测试。

生产模拟盘 SQLite 的隔离备份上完成幂等迁移：30 笔历史成交、16 个持仓、1880 条原始净值、六个账户的现金/本金/旧权重逐行摘要保持不变；从真实可用记录生成 18 条每日快照和六个风险状态。未伪造更早的历史。

发布前为五个实际持仓证券获取带时间的公开报价并预置最后可信估值，避免冷启动时回退成交成本。最终估值仍可能随行情源和有效时间变化，属于重估而非新增交易收益；跨源差异仍需要继续审计。

曾发现隔离测试的静态战报路径仍指向生产默认路径，影响了公开静态摘要，未影响账户主账。已恢复真实战报，测试 fixture 与测试命令均显式隔离战报路径，并补中性情绪 fixture，避免网络/时段影响测试。
