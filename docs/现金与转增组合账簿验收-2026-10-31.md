# 现金与转增组合账簿验收

本轮把现金分红账簿和转增数量库存组合为同一份有来源指纹的离线研究账簿。目标是避免除权后原始价格与旧股数量相乘，遗漏新增股份而产生虚假净值损失；不是通过补记权益来美化原策略结果。原价格、事件重放、现金税务、股份库存模块字节不变，没有生产或券商操作。

## 组合行为

`quant_capitalization_book` 持有现金账簿、股份库存、原始价格标记和统一状态摘要。登记日收盘从真实执行的模型现金持仓自动快照，不接受另一套独立声明的旧股数量；后续转增登记包含此前已入账新增股，防止遗漏或重复。尚未确定获配的零碎股不能被当成整股参加下一次登记。

开盘先使用原现金账簿生成分红应收，再确认当日转增待收；开盘不直接入账转增股份。股份计划入账日在收盘按明确的日期模型尝试入账，整数权益可以完成数量入账，零碎权益缺确认则继续待收。该收盘时点是研究假设，不是券商到账时间认证。

估值将旧股、现金与现金分红应收留在原现金账簿，将转增待收或已入账股单独计价一次。新增股份不增加可用现金；分红支付按原账簿将应收转换为现金，原个人税模型仍扣除预留。未确认零碎权益同时给出精确比例及整股分配上下界，不能伪装成已获配股数。当前原始标记必须为正的分位价格；缺少、未来、非有限或超界标记均拒绝。

资本公积/送股的税基、成本与持有期继承没有获得权威清算证据，因此：

- 发生相关权益后，拒绝受影响证券的买卖；其他证券可继续使用原现金账簿。
- 新增股要参加后续现金分红登记时拒绝处理，不能只登记旧股或臆造税务批次。
- `complete_after_tax_nav` 和 `strategy_risk_nav` 均为空，交易和晋级标记保持 false。所谓现金分红税预留后净值只是组合估值分层，未涵盖新增股所有税费及限售流动性折价。
- 重放必须另行验证总收益信号、除权参考价、税基、订单和完整事件覆盖。没有将本账簿接到原策略风险线、重置暂停或提高样本外成绩。

状态校验绑定 scope、七份加载源码摘要和两个组件版本，统一摘要覆盖现金与股份，支持有界 JSON 恢复。源码失配、登记后修订/删除、会话内换证据、迟到登记、盘后才观察到的历史登记以及不合格获配确认均拒绝。摘要用于完整性和版本约束，不等于真实账户认证。

## 可操作离线入口

`scripts/quant-capitalization-review.py --plan <绝对路径> --workspace <全新绝对目录>` 接受显式价格/持仓角色、初始资金、日历、现金事件、转增事件、原文、逐日开收盘标记及已声明的成交。它不生成策略信号或下单。

入口冻结输入和原文，保存逐日开收盘估值及最终完整收盘检查点；若某日开盘、成交或收盘失败，只保留之前已完成的收盘账簿，不保存半完成状态为可恢复终态。输入限制2MiB、原文单份10MiB/合计25MiB、估值日志10MiB、状态16MiB。非完整结果退出2：`awaiting_allotment`、`not_available_as_recorded` 或 `rejected`，不把资料未知当成无权益，也不把未知结果标成功。

新增34项定向测试通过，包含有活跃成交的现金/股份守恒、开盘应收与收盘入账、零碎上下界、显式获配、连续两次转增、后续分红拒绝、受影响与其他证券交易、未知可卖日、无事件路径与原现金账簿逐日全等、JSON恢复、来源修订、账号/摘要、盘中迟到、恶劣十进制环境及真正子进程 CLI 失败留档。

`artifacts/quant-capitalization-composite-20261031/real-fact-model-review.json` 及四个 `*-review` 留存了此前已核对宁德时代2023-037原文接入后的四案。原文 SHA256 为 `8063ac7204c79d9f856b7a2e21887aa650bc5e2b2c1bbbecb81ab54473d0939b`。**持仓和原始价格标记均为反事实模型，未验证真实历史价格；该事件在原两组实验区间外，未新增回测或样本外证据。** 现金事件构造中的参考调整字段是声明场景值，组合估值没有使用它推定交易所除权参考规则。

100股模型在除权前后组合总值相同，新增80股没有进入可用现金；1股保留0.8精确待收权益和整股上下界；实存模式报告当时资料不可用；除权日卖出被拒绝且保留登记日完整收盘检查点。实际外部清算、股份成本继承、全市场经济事件与真实行情集成仍待验。

本轮另核对原两组封存实验文件、31笔现金事实清单及原价格引擎摘要均保持原值。完整提交树回归结果留 `artifacts/quant-capitalization-composite-20261031/final-verification.json`。本组件没有共享 API 或 UI，也未被原一小时负载覆盖；没有提名挑战者、发布新策略或上线。商业级内部研究整体仍未完成。
