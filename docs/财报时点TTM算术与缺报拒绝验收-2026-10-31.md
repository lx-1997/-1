# 财报时点TTM算术与缺报拒绝验收

这是新基本面信号之前的数据基础，目标仍为内部研究的商业级质量。本轮新增独立离线算术模块/CLI，不改原财报读取器、财报入库时钟、价格/事件内核、两组实验、31现金事实或策略门槛，不产生因子排名、交易信号、收益或新OOS结果。

财政部公开答复明确中期现金流量表提供年初至中期末及上年可比期间累计数，不能把每季累计直接相加当TTM。[财政部2023-01-29答复](https://www.mof.gov.cn/bd/mhwzzxly/hjs/202301/t20230129_3864201.htm)。准则原文网页一次读取超时；公开答复已另作一次固定GET并保留原始HTML及SHA256。**本工具的TTM是基于已核对累计期间的算术推导，不称准则要求披露的TTM字段或财务可比性认证。**

## 算术和知识时点

只支持现有读取器的日历年、合并口径、人民币、年初累计三类金额流量指标：营业收入、归母净利润、经营现金流量净额。不接最新值接口，不转换万元/外币，不将资产负债时点量当流量，也不生成单季拆分、比率或“净利润减CFO”的混口径应计因子。

中期TTM = 当年累计 + 上年全年 − 上年同期累计；年末直接使用该年全年，避免重复加减。三个部件都以同一issuer/code/时钟/模式经过现有原文、索引、修订链校验，不能把当前版和当时版拼接。修订当天仍保留旧版，次日才可见；当时实存模式还受原文采集/事实记录时间约束，其元数据不等于外部时间证明。TTM窗口按日历月确定，不用固定365日。

金额先转整数分再作有符号加减，无浮点或环境Decimal舍入依赖；源读取的Decimal校验使用局部80位标准上下文，不改变调用方环境。输入事实深拷贝、源字节私有绑定、运算前后核对已加载源码；CLI有单文档/总字节限额、严格JSON/重复键拒绝、路径及前后字节复查，不覆盖旧报告。

缺一个期间就status=unavailable，缺最新修订字段就incomplete，整组metrics=NULL；不补0、不年化一季、不退到旧完整修订或其他期间，CLI留拒绝报告并退出2。完整算术仅标arithmetic_available。**所有结果usable_for_strategy、accounting_comparability_verified、historical_pit_feed_certified、promotion_allowed及commercial_ready固定为false**；同币种/同合并标签不能证明会计政策、合并范围和追溯重述口径一致。年度原文与比较数字仍需各自人工来源核对。

## 已执行验证

新增31项，相关89项通过，含三种中期窗口、年度直接路径、正负/零/大额精确分、极低Decimal精度与陷阱、公告/记录/更正前后、当期与两个历史部件分别修订、缺新版字段不回填、未来修订不改旧视点、不同单位/口径/最新快照/来源或代码漂移拒绝，以及CLI计算后改写输入不落盘。正算术路径为明确合成的隔离夹具，没有注入应用或生产。

实际用原002109两版一季报及其原PDF/索引在七个查询中运行CLI：公告前/后、更正当日/次日、旧时点实存/当前元数据实存、缺年度报表。当前部件在应有时点选择原版或更正版；**真实TTM七次都不可用**，因为该留存样本没有2024年度和2024同期YTD的完整部件。NULL不是零，也不能用最新接口补成成功。独立标准库程序不导入项目模块，逐一从原manifest重算可见时间、文档选择及缺部件，七次全部相符；原manifest/PDF/索引摘要不变。

已留存的[2026-04-30更正公告](https://static.cninfo.com.cn/finalpage/2026-04-30/1225265724.PDF)涉及2024年度至2025三季报，所以补齐2024年报还须保留已知更正链，不能只找一份年报就宣称可用。现有原季度报告和更正记录不构成完整可比财务面板。没有为展示正数而拼接未经核对的比较数字。

源为`quant_financial_flows.py`、`quant-financial-flow-review.py`；原文和七次实际报告/独立核验在`artifacts/quant-financial-flows-20261031`，薄摘要`quant-financial-flow-review-20261031.json`。新增模块不被当前API导入，不影响正在运行的冻结事件负载；该负载必须等待自己的正式终态。整体验收仍缺完整PIT/权利/清算/可执行性、新策略未见验证与生产SLO，目标保持未完成、未部署。


复现一个已见原版视点（输出名必须全新，预期保留unavailable并退出2）：

```sh
python3 scripts/quant-financial-flow-review.py \
  --manifest docs/quant-reviewed-financial-vintages-sample-20261031.json \
  --evidence-dir artifacts/quant-financial-vintages-20261031/reviewed-evidence \
  --issuer-id cninfo:9900002009 --symbol 002109 --period-end 2025-03-31 \
  --as-of 2025-04-25T00:00:00+08:00 --mode historical_reconstruction \
  --metrics revenue parent_net_profit net_operating_cashflow \
  --output artifacts/quant-financial-flows-20261031/new-unavailable-review.json
```


补充发现：以明确的隔离夹具，将调用方Decimal精度降至3，直接旧读取器会把超过其1e18元上界1分钱的源金额接受为available；新TTM层在局部80位上下文中正确拒绝。该反例留`legacy-context-probe.json`，不是生产发生的错误或真实证券财务金额。**旧直接读取器本轮未修复**，后续须使其金额边界校验不依赖环境精度，同时保全已入库财报档案的版本/来源身份，不能为修一行而使旧档案静默失效；这也是整体继续未达标的明确问题。
