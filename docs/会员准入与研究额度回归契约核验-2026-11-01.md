# 会员准入与研究额度回归契约核验

本轮关闭的是5项过时的测试契约失败，未修改生产会员、额度或策略门槛。旧测试仍假定匿名用户有免费研判次数；现行两个准入函数已经明确要求会员或管理员，匿名403、普通账号402。旧版5项失败在独立精确副本重新取得，日志保留。

更新后的测试分两层：

- 真实准入函数配合隔离的模拟会员记录，验证匿名/普通账号在执行模型前拒绝，premium/lifetime/admin按现行规则返回不限次数。新增两个入口连续完成两次请求的检查，不注入有限额度；流式入口实际核对生成器关闭。
- 保留成功计费、降级不计费、执行前预留、断开释放、辩论使用快速额度和后置澄清释放等生命周期断言。由于生产会员当前不限次，这层在真实会员准入之后明确注入测试专用的一次额度，再检查实际SQLite租约。它不是恢复匿名免费规则，也不能当成当前生产会员有限额度的证据。此测试专用额度耗尽使用429，普通账号的真实准入仍是402、匿名仍403。

测试共保留原5个案例并新增12个参数化案例。相关权限/额度、研报缓存和通用缓存在最终Git精确副本合计78项通过（9项警告）。主服务只纠正了两处过时说明注释；对改动前与当前完整main.py的AST比较完全相同，未变更生产行为。不是为了通过旧测试而放宽准入，也没有关闭测试中的权限闸。

所有模型执行为测试桩，用户记录为本机模拟记录；身份验证是在函数层测试，不冒称真实JWT会员浏览器或生产账号验收。测试内存持久化入口被隔离，额度库使用每个测试的独立临时路径。未采购、安装数据/模型依赖，未调用实际付费模型或生产服务。
