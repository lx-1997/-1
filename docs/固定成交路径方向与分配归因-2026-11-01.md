# 固定成交路径方向与分配归因

两组失败均不能仅归咎于手续费。预先固定公式后，按原535日OOS成交路径拆解价格盈亏；该区间已见，不是新的样本外验证。没有搜索参数、重置风险或挑选候选。

前两行相加，再扣成本，等于净收益；参照加分配残差，再扣成本，也等于净收益。两种表达不能再次相加。原两组最大回撤、风险暂停和失败结论均未修改。

参照的构造：隔夜使用上一收盘实际总持仓市值，乘原篮子全部股票等权隔夜涨幅；日内使用当天实际成交后按开盘价计的总持仓市值，乘篮子等权开收盘涨幅。实际盈亏减参照为分配残差。它以实际路径为条件，包含实际交易后敞口，不是可执行策略，不代表无前视的新信号、市场Beta或因果Alpha；残差不能简单命名为选股能力。未纳入分红、利息、完整公司行为或总收益基准。

第一组在隔夜和日内都亏损，第二组价格损失主要发生在隔夜；两组在同敞口参照下均存在负分配残差。合理的后续顺序仍是补齐时点一致的总收益与执行数据，再按新协议研究信号。不能由这份归因直接推出“改等权”“避开隔夜”会通过门槛，也不据此启动新参数搜索。

实现使用字符串转有理数，逐日核对NAV并显式分离分币取整残差。原真实两组的该残差均为0。独立检查不导入归因模块，另以整数分重建现金、数量和收盘净值，并以90位Decimal重算参照；两组各535日、58/120笔成交全部核对。原实验文件SHA、研究内核SHA及结果摘要保持封存身份。新模块9项测试覆盖实际买入、部分卖出、隔夜、成本、空仓、分币残差与无效路径拒绝。
