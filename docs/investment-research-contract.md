# Investment Research workbench implementation contract

Seven genuinely executable tools, grouped into three workflows. Existing statement review remains separate.

- Strategy: `performance` (QuantStats), `portfolio` (Riskfolio), `factors` (Qlib).
- Company: `financials` (FinanceToolkit), `institutions` (EdgarTools).
- Assets: `funds` (fund holdings lookthrough), `bonds` (convertible bond screening).

API: authenticated GET `/api/research-tools/catalog`; GET `/api/research-tools/templates/{tool}`; POST `/api/research-tools/jobs` with `{tool, input, request_id}`; GET `/api/research-tools/jobs/{id}`; DELETE same path cancels/deletes. Job ownership uses real current user, not caller input. Job returns `{id,tool,state:'queued'|'running'|'completed'|'failed'|'cancelled',created_at,updated_at,result?,error?}`. Results are private temporary memory, expire in 30 minutes and may disappear on deployment; export reports before closing. No account, holdings, or orders are written. Frontend cancels requests on close/logout and clears all results on auth revision.

Domain functions `analyze_<tool>(data:dict)->dict` take JSON input and return unified report:

```
{tool,title,engine,summary:[{label,value,unit?,tone?}],
 tables:[{key,title,columns:[{key,label,type?:'text'|'number'|'percent'|'date'}],rows:[object]}],
 charts:[{key,title,type:'line'|'bar'|'heatmap',data:[object],x_key?,series?:[{key,label}],matrix?:number[][],labels?:string[],unit?,value_type?}],
 warnings:string[],methodology:string[],sources:[{name,url?,as_of?,coverage?,currency?}],report_html?:string}
```

Domain exceptions must be actionable ValueError (bad input), RuntimeError (dependency/config/source unavailable). No fake success/data or automatic demo rows. Float outputs must be finite or null. User filenames/text must never become shell commands or arbitrary URLs.

All tools accept uploaded **data**, not arbitrary URLs. CSV file input supplied as `file_name` + `content_base64`; use stdlib csv UTF8/GB18030, strict size 2MiB/rows5000. Each domain owns its specific CSV parsing/headers and safe JSON records; imported records permit real analysis even when live data source unavailable. Template data must be explicitly marked fictitious and require explicit user selection before use. Accept JSON datasets too, but validate size and shape.

## Inputs / semantics

- performance: `returns:[{date,return,benchmark_return?}]` decimal daily returns (not percentages); OR `net_values:[{date,value,benchmark_value?}]`, mutually exclusive. Optional `currency`, `name`, `risk_free_rate` annual decimal. Min30 unique ordered dates, no impossible return <=-1; no divide realized trade PNL to construct account returns. Genuine QuantStats metrics/HTML, no auto Yahoo download.
- portfolio: `prices:[{date,symbol,close}]`, `weights:[{symbol,weight}]`, `currency`, optional `fx_normalized:boolean`. All assets must have same valuation currency/adjusted consistent closes. Min60 common dates, max20 symbols; positive weights sum1. Actual Riskfolio risk contributions/cluster and covariance, historical CVaR; no orders or financial advice execution.
- financials: `records:[{symbol,period,currency,revenue,net_income,operating_cashflow,capex,total_assets,total_equity,total_debt,current_assets?,current_liabilities?,receivables?,inventory?}]`; up to8+ periods and20symbols; consistent quarter/annual basis explicit `period_type:'quarterly'|'annual'`. Optional `symbols` live fetch may be added if proper historical data available; never fabricate old periods from newest snapshot. Genuine FinanceToolkit formula module computations on provided data, no FMP/Yahoo auto-fetch. Same period peers only, missing values stay missing.
- institutions: `cik` digits (institution SEC id), `form:'13F-HR'|'4'`, optional `compare_previous:true`; also accept `records` normalized holdings OR official XML via file input. Live SEC access must use environment SEC identity; no email hardcoded/committed. Preserve filing/report dates; 13F is disclosed historical holdings, never call real-time. Aggregate multi-class/option positions by identifier+put/call before diff, no missing prior treated zero.
- funds: `holdings:[{fund,symbol,name?,weight,sector?,as_of}]`, optional `positions:[{symbol,weight}]` portfolio weights; optional `direct_positions:[{symbol,weight}]`. Holdings weights decimals, disclosed fund coverage <=1, no normalize partial holdings to100%; show unreported portion; compute overlap only for compatible dates, warn differing dates. Uploaded issuer/authorized data; no academic-only commercial feeds. Up to20funds/5000holdings.
- bonds: `records:[{symbol,name?,price,conversion_price,stock_price,years_to_maturity?,redemption_price?,redemption_status?,redemption_date?,put_date?,rating?,volume?,as_of}]`. Compute conversion value=stock_price/conversion_price*100, premium=price/conversion_value-1, double_low=price+premium*100; YTM only when schedule is supplied or clearly mark simplified gross approximation (no precise YTM from face value alone). Filter liquidity, maturity, redemption events; retain missing terms as unverified. Optional filters `max_price,max_premium,min_volume,exclude_redemption:true`. No trade execution.
- factors: `prices:[{date,symbol,open,high,low,close,volume}]`, max20symbols/5000records. Actual Qlib workflow/feature expressions and LightGBM, chronological train/test split with purged forward label horizon, no shuffled fit, max50trees/threads1. At least180 dates and5symbols, train/test dataset provenance, IC/rankIC/evaluation; no forecast guarantees. Separate bounded worker. Labels only use future return inside training/evaluation; last unavailable labels omitted; test untouched during feature selection. No account/order write.

Frontend: a single drawer/dialog opened from QuantLab plus full-app positions, seven working tabs/form flows, clear dataset types and downloadable templates. Prefer uploaded data for analytics, live SEC query plus disclosure-file import for institutions. Data remains local until explicit Run. Sources and as-of visible; cancellation/loading/errors accessible; mobile320px no page overflow. Add authentication-bound API functions/types to existing researchService.ts. Generic report presentation keeps shapes aligned. Results export JSON/CSV; QuantStats HTML download as attachment. No fabricated results on first open.

Live history: portfolio/factors also accept `symbols`, `start_date`, `end_date`, `currency`, and portfolio `weights`. Reuse platform verified real history, two concurrent source requests, maximum five years/5000 rows, exclude the unclosed current day, reject synthetic or unavailable data and mixed valuation currencies. Retain source, fetch timestamp and adjustment method on every price row. Reject unknown, raw or inconsistent adjustment methods even if the source is genuine. Do not mix live queries and imported prices.

Live financials: `symbols` accepts 1–5 US tickers; fetch eight actual SEC fiscal quarter ends and historical filing versions before FinanceToolkit calculations. Derive standalone-quarter flows only from compatible year-to-date filings. Missing balances and unresolvable historical versions stay null. Compare peers only at an identical actual fiscal date.

Runtime: install `backend/requirements-research.txt` in a separate Python 3.11 environment. Production defaults to `/opt/deepfocus/research-runtime/bin/python`, configurable with `DEEPFOCUS_RESEARCH_PYTHON`. Store the SEC identity in a 0600 JSON file containing `sec_identity` outside the repository; production defaults to `/opt/deepfocus/research-runtime-config.json`, configurable with `DEEPFOCUS_RESEARCH_CONFIG`. Never commit contact identity or account credentials. Worker receives an allowlisted environment, temporary caches and a temporary MLflow SQLite store; one cross-process file lock, one compute slot, an explicitly single-worker API service (memory job registry is not shared across workers), single-thread libraries, 120-second timeout, process-group cancel/reap and 30-minute private-memory retention. Catalog reports actual installed versions. File-only funds/bonds remain independent of external market services.

Production compatibility: the API Python links SQLite 3.26. Recent MLflow needs SQLite >=3.31 for its temporary tracking store. An official `pysqlite3-binary==0.5.4.post2` wheel supplies SQLite 3.51.1; a runtime-local `sitecustomize.py` alias is installed only inside the analysis venv. Keep this out of the API environment and verify autoload with PYTHONPATH removed. Record the alias/wheel SHA and rerun a real Qlib fit after runtime changes. macOS analysis used native SQLite and Homebrew libomp for LightGBM.
