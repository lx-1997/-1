# 终端首屏与正文线上实测

2026-10-29，实际打开 https://daocaijing.com/，用浏览器交互核验电脑 1440×900、手机尺寸 390×844 / 320×740。手机为浏览器视口测试，不代表实体手机验收。未使用 metrics dashboard 的令牌。

## 实测发现与修复

- 手机日历原来折行约 189px，改成单行横向浏览，最终测量 39px。
- 手机旧偏好会展开三张头条大卡，把普通快讯推到首屏外。新增独立手机偏好，默认收起，保留手动展开；电脑保留原偏好。
- 早茶文章已有全文被错误截成 77 字：短条目误判为推荐卡片，中文长句又误判为标题。后端保留早报类短条目并过滤订阅尾巴，针对这类文章升级缓存标识；前端把中文多分句长句按正文呈现。
