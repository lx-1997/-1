# 财报流量、存量与补充提取版本契约验收

2026-10-31。内部研究新离线能力：quant_financial_fact_store、quant-financial-facts.py 和恢复v6。原财报入库/版本选择/TTM源码及旧清单不变；补充提取在同一研究库独立表保存，不覆盖原公告事实或回执。

## 类型与来源约束

补充事实必须绑定同owner的原回执和其中明确的公告ID、PDF SHA256、物理页。原文已由原入库层校验留存字节、索引中的发行人、日期和公告身份；新层不自动证明PDF单元格语义。若原清单在多个期间重复用同一个公告ID，新层拒绝歧义绑定。

支持集团净利润、少数股东损益及已声明的现金流调节项为year_to_date流量，只允许current_period，起止日期必须等于所属原报表。total_assets是point_in_time_stock，period_start必须NULL，日期由当前期末/上年度末/上年度末调整后列决定；资产不能伪装成YTD。所有输入继续采用不超过1e18元、最多两位小数的CNY原始金额或显式NULL，不用环境Decimal精度放宽边界。端点平均资产的半分钱尚不作为原始金额存入，也没有开放派生比率/TTM接口。

## 提取更正与公告修订分开

每个parent的补充提取是显式线性完整快照：首次须有事实；后来版本必须指定当前末端supersedes_packet_id，事务内禁止分叉。新增key不改旧key；若修改数值、页码、日期等已有事实，或撤回旧事实，必须对每个变更key分别给出8至500字的更正原因。新增事实不能附带伪更正原因，未变快照不能堆叠成新版本；同输入重试返回原ID。原版快照和更正理由永久保留，不把新提取说成发行人公告修订。

查询总是指定补充快照ID。先按知识时点从原回执选择当时最新公告，再从指定完整快照查该公告的新指标；缺少新版事实、撤回或披露空白都不可用，不补旧公告值，也不跨提取快照拼接。历史重建显式使用晚采集事实重建已见历史；as_recorded则同时检查父回执和补充提取各自实际入库的北京时间次日边界，不能借旧父回执的时钟提前用后来提取事实。

只读查询在同一个SQLite事务中验证来源、所属账户、原回执指纹、提取链和边界，显式关闭连接；边界前fact整体为NULL。新表有不可变触发器、owner级100份/10MiB元数据额度、每份2MiB/1000事实限制、事务时钟和60秒预算。它们是本机应用约束，不是外部时间公证或生产容量证明。

## 可复现离线入口

公共原文人工核对样本为quant-reviewed-typed-financial-facts-sample-20261031.json：43项事实，含5份集团净利润、两年度现金流调节和6资产时点，两个处置损益空白保留NULL。部分新增利润引用此次额外目视的2025Q1更正版第9页与2024更正年报第96页，数值与先前独立更正报表一致。该输入须绑定原五版本报表回执，不能绑定到缺报父档案。

```sh
python3 scripts/quant-financial-facts.py --db /absolute/research.sqlite3 --owner OWNER put \
  --parent-id PARENT_RECEIPT_ID --label '人工核对的补充财报事实' \
  --input docs/quant-reviewed-typed-financial-facts-sample-20261031.json
# 已有提取时，在完整新输入上显式加 --supersedes-packet-id PREVIOUS_PACKET_ID。
python3 scripts/quant-financial-facts.py --db /absolute/research.sqlite3 --owner OWNER review \
  --id PACKET_ID --issuer-id cninfo:9900002009 --symbol 002109 \
  --report-period-end 2025-03-31 --metric total_assets --column previous_year_end \
  --as-of 2026-05-01T00:00:00+08:00 --mode historical_reconstruction
```

输入仅facts与correction_notes两个字段；更正原因列表每项包含document_id、metric、column、reason。CLI返回0表示原始事实可用，2表示缺失/空白/时点不可用，1表示无效请求或非所属账户记录。未提供公共API、UI或交易信号，usable_for_strategy/PIT/comparability/promotion/commercial_ready固定false。
