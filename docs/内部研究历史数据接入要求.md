# 内部研究历史数据接入要求

范围：内部研究、达到商业级质量，不出售原始数据或交易信号。当前未确认新增供应商账号或接入权限；此文是验收输入要求，不是采购建议或已有数据完整性的声明。已有公开日线/公告可以继续用于明确标注的开发诊断，不能据此认证完整时点证券状态。

## 必须交付的数据契约

| 数据 | 必需字段和时点 | 拒绝条件 |
|---|---|---|
| 证券身份和历史股票池 | 稳定证券ID、各时段代码/市场/板块、上市/摘牌日、历史成员区间、变更公告可用时间 | 只提供当前存续列表；代码复用或更名无法关联 |
| 每日/区间交易状态 | 交易日、ST/其他风险警示、停复牌、退市整理/重上市、无涨跌幅限制状态、状态生效区间、公告可用时间 | 缺失状态被默认为普通股；用当前ST名单回填历史 |
| 逐日可执行价格约束 | 官方前收盘/除权息参考、上下限价、最小报价单位、无幅限制的显式原因、适用规则版本 | 用价格没越界反推非ST；只按代码统一10%/20%认证状态 |
| 原始不复权行情 | OHLC、成交量和成交额、股/手量纲、币种、完整会话范围、抓取与修订时间、原始响应/摘要 | 静默取日期交集、填充缺价、将缺日当停牌、来源修订不可追踪 |
| 完整公司行为 | 现金/送转/拆并股/配股等类型，公告可用/登记/除权/上市可卖/支付日，实际现金和参考调整分别提供，撤销/修订链 | 预案当实施；只有报告期目录；现金红利与除息调整额混用 |
| 基准 | 明确价格/全收益/净收益变体、税制、币种、时间锚、历史方法/修订及费用差异 | 缺开盘却虚构开盘；固定税率指数冒充个人FIFO税后收益 |
| 数据使用范围 | 可核对的内部使用依据、保存/备份/衍生研究结果权限及账号额度 | 仅凭“公开可访问”或账号存在就标授权完成 |

每条事实至少分开记录 `effective_at`（何时生效）、`available_at`（当时何时可知）、`observed_at`（本系统何时取得）、`revision` 和原文/响应SHA256。供应商回补历史与当时系统已存事实分别使用，不能把后补资料倒填为当时已知。

首批必须覆盖原实验六股2023-10-26至2026-10-29，以及新闻策略声明股票池；证券状态日期要与各自行情严格对应。为了检验生存偏差，最终股票池数据还必须覆盖研究期间已退市、ST、IPO等证券，不能把这六只存续股票当作全市场验证。扩大股票池或换信号须独立登记研究协议，不能追加到旧OOS或旧留出冒称未见样本。

## 接入验收顺序

1. 先核对账号产品与内部使用范围，绑定有限证券、日期、字段及请求额度；保留原始请求/响应/错误，不把空响应当完整历史。
2. 核对至少一个真实ST切换、停复牌、上市初期/重上市无幅限制、退市及公司行为样本；逐条关联官方事实与源发布时间。样本一致不等于全量覆盖。
3. 批量检查全范围日期/身份/状态覆盖和修订冲突，缺字段/日期明确拒绝或隔离；不能自动设 `verified=true`。
4. 在隔离库与现有固定路径配对核验；成本、风险和选参规则保持，所有失败留存。数据修正产生的新路径属于已见开发数据。
5. 只有数据契约和候选资格分别满足，才冻结版本进入真正未见数据验证；供应商接入成功不代表盈利验证或可以上线实盘。

当前差距仍为完整历史证券状态/时点股票池、全经济事件、数据使用条款及未见收益证明；标准限幅函数、年度日历和已有31笔现金事件不能替代这些输入。
