## 当前推进顺序

1. 补全两组每只证券覆盖期内的公司行为原始证据、来源、公告日期与采集日期，核对现金单位、登记/除息/支付和差异化除息参考。缺失、晚到和修订不得悄悄回填。
2. 从固定路径遗漏核验推进到新版本的事件驱动账务与信号，处理分红应收、到账、FIFO 税务及送转配股可卖时间；保持原风险与成本门槛。不能把给旧结果加分红当作完成新策略回测。
3. 先验证数据与收益基准，再另立新的研究协议；旧数据均已见，不把修正后的开发结果重新标为全新 OOS。上一份协议的“没有合格候选”结果保留。
4. 候选有资格后再冻结版本，采集未见数据、并行影子跟踪和强度验证。没有资格时继续做数据与方法改进，不硬开账户，不将等待时间冒充验证完成。
5. 同步完成商业服务工程与权利证据；只有账本全部要求分别有相称的真实证据后，才能宣称达标。

## 2026-10-30 本轮实现与验证

新增现金分红模型分离公告可用时间与实际采集时间，保留连续修订、原文 SHA256 和原文留存；重复/迟到/已入账修订拒绝静默处理。税前现金每股分配额与除息参考调整额独立，未知送转配股不假装支持。

固定路径核验依据登记日收盘持仓，除息形成应收、支付日转为税前已付现金。它不改原成交、净值、策略信号或风险峰值，未解决税务与完整事件覆盖前一律不得用于晋级。另有税前收益指数与除息参考价核验函数，尚未接入生产信号或交易。

两条原文实际下载并保留，茅台来自发行人官网，美的来自发行人公告的新浪镜像（官方归档链仍待补证）。两条公告只作为真实抽样，不能标记两组完整公司行为已覆盖。真实重建得到第一组该笔分红权益为 0、第二组为 8100 元；按当时系统实际留存模式均为 0，明确表明今天补采的证据不能冒充当时已留存。该模式的 0 不表示经济上没有分红。

单日经济收益核验：茅台 2024-06-18→19 价格 -1.3474%，加该笔税前现金为 +0.6820%；美的 2024-05-14→15 价格 -1.5246%，加该笔税前现金为 +2.7103%。这不是组合策略收益，也没有给原失败实验改成通过；完整重放还会影响选参、持仓与风控，不能用固定路径加回代替。
